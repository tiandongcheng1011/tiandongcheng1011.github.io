一、复变函数论核心名词、定义与几何意义

  • 复数 ( z = x+iy )：有序实数对，( i^2=-1 )。几何意义：复平面上的点 ( (x,y) ) 或从原点出发的向量。加法满足平行四边形法则。

  • 实部 / 虚部：( x = \operatorname{Re}z,\ y = \operatorname{Im}z )。几何意义：向量在实轴与虚轴上的正交投影。

  • 共轭复数 ( \bar{z} )：( \bar{z} = x-iy )。几何意义：关于实轴的镜像对称点。若 ( z ) 在上半平面，( \bar{z} ) 必在下半平面。

  • 模 ( |z| )：( |z| = \sqrt{x^2+y^2} )。几何意义：向量长度。乘法时模相乘。

  • 辐角 ( \operatorname{Arg}z )：实轴正向与向量 ( z ) 的夹角，多值：( \theta + 2k\pi )。几何意义：向量的方向角。乘法时：模相乘，辐角相加（产生旋转）。

  • 辐角主值 ( \arg z )：限制在 ( (-\pi, \pi] ) 内的辐角。几何意义：标准化后的唯一角度，常用于初等函数单值化。

  • 指数式 ( z = re^{i\theta} )：由欧拉公式 ( e^{i\theta}=\cos\theta+i\sin\theta ) 导出。几何意义：极坐标表示，将乘除与幂运算转化为模与辐角的加减。例：( 1+i=\sqrt{2}e^{i\pi/4} )。

  • 棣莫弗公式：( (e^{i\theta})^n = e^{in\theta} )。几何意义：复数 ( n ) 次幂相当于辐角旋转 ( n ) 倍，是旋转和伸缩的迭代。

  • ( n ) 次方根 ( \sqrt[n]{z} )：( n ) 个值：( \sqrt[n]{r}e^{i(\theta+2k\pi)/n} )。几何意义：( n ) 个点均匀分布在半径为 ( \sqrt[n]{r} ) 的圆周上，构成正 ( n ) 边形。例：1的立方根为 ( 1, \omega, \omega^2 )。

  • 区域 ( D )：连通的开集。几何意义：复平面上没有“洞”或“裂缝”的一片连续点集，是解析函数的天然定义域。

  • 单连通域：任意简单闭曲线可连续收缩为一点。几何意义：无洞的区域。在此类域上解析函数的闭路积分为零（柯西定理）。例：圆盘、上半平面。

  • 导数 ( f’(z_0) )：( \lim_{\Delta z \to 0} \frac{f(z_0+\Delta z)-f(z_0)}{\Delta z} ) 存在且与路径无关。几何意义：若 ( f’(z_0) \neq 0 )，则局部映射为伸缩旋转。

  • 解析函数：在区域 ( D ) 内处处可导。几何意义：局部可展为幂级数，具有极强的刚性。非常数解析函数把开集映为开集，且内部无最大值（最大模原理）。

  • 柯西-黎曼方程：( u_x = v_y,\ u_y = -v_x )。几何意义：保证导数的存在，映射的雅可比矩阵形如 ( )，在几何上就是局部伸缩-旋转。

  • 调和函数：( \Delta u = u_{xx}+u_{yy}=0 )。几何意义：解析函数的实部和虚部都是调和函数。其等值线（等高线）与共轭调和函数的等值线在 ( f’ \neq 0 ) 处处正交。例：( u=x^2-y^2 ) 的等值线是等轴双曲线。

  • 共轭调和函数：给定 ( u )，求 ( v ) 使 ( f=u+iv ) 解析。几何意义：从 C-R 方程出发，由 ( dv = -u_y dx + u_x dy ) 通过线积分求出 ( v )。几何上是寻找与 ( u ) 的等值线正交的曲线族。

  • 指数函数 ( e^z )：( e^x(\cos y + i\sin y) )，周期 ( 2\pi i )。几何意义：将水平带状区域映射为角形区域。竖直线映为圆，水平线映为射线。

  • 对数函数 ( \operatorname{Ln}z )：( \ln|z| + i\operatorname{Arg}z )，多值。几何意义：指数函数的反函数。支点为 ( 0,\infty )。

  • 复积分 ( \int_C f(z)dz )：沿有向曲线 ( C ) 的第二类线积分。几何意义：可分解为实部、虚部向量场的环量与通量。解析函数的积分与路径无关。

  • 柯西积分定理：若 ( f ) 在单连通域 ( D ) 解析，则 ( \oint_C f(z)dz=0 )。几何意义：解析函数在无洞区域内的积分环路可自由变形收缩，积分值不变。

  • 柯西积分公式：( f(z_0) = \frac{1}{2\pi i}\oint_C \frac{f(z)}{z-z_0}dz )。几何意义：解析函数的内部值完全由边界值决定，这是刚性的一种表现。类似于静电场由边界电势唯一确定。

  • 高阶导数公式：( f^{(n)}(z_0) = \frac{n!}{2\pi i}\oint_C \frac{f(z)}{(z-z_0)^{n+1}}dz )。几何意义：解析函数可无限次求导，且导数仍由边界积分表示。

  • 泰勒 / 洛朗级数：全纯圆盘内展为 Taylor 级数 ( \sum a_n(z-a)^n )；圆环内展为 Laurent 级数 ( \sum c_n(z-a)^n )。几何意义：Taylor 级数对应无奇点区域；Laurent 级数中负幂项刻画了孤立奇点处的“场”形态。

  • 孤立奇点：可去奇点、极点、本性奇点。几何意义：极点附近模趋于无穷，像点“冲向无穷”；本性奇点附近取值异常复杂，在每个邻域内像集稠密。

  • 留数 ( \operatorname{Res}(f,z_0) )：Laurent 展开中 ( (z-z_0)^{-1} ) 的系数 ( c_{-1} )。几何意义：积分 ( \frac{1}{2\pi i}\oint f dz ) 的度量，反映奇点处的“涡旋”或“源”强度。

  • 留数定理：( \oint_C f = 2\pi i \sum \operatorname{Res}(f, z_k) )。几何意义：将闭路积分归结为围道内部所有孤立奇点留数之和，是计算复积分和实积分的核心工具。

  • 辐角原理：( \frac{1}{2\pi i}\oint_C \frac{f’(z)}{f(z)}dz = N - P )。几何意义：当 ( z ) 沿围道绕行一圈时，映射像 ( f(z) ) 绕原点的圈数 = 内部零点数 - 极点数。

  • 路西定理：若在围道 ( C ) 上有 ( |f(z)| > |g(z)| )，则 ( f ) 与 ( f+g ) 在 ( C ) 内部零点个数相同。几何意义：用于判断解析函数在区域内的零点数目，是辐角原理的推论。

  • 共形映射：解析函数在 ( f’(z) \neq 0 ) 处保持两曲线夹角的大小和方向不变。几何意义：局部上是一个相似变换，把无穷小圆映为无穷小圆。是整个复变函数几何理论的核心。

  • 分式线性映射 ( \frac{az+b}{cz+d} )：( ad-bc \neq 0 ) 的变换。几何意义：圆周和直线仍变为圆周或直线（保圆性），保持关于圆或直线的对称性，且保持四点交比不变。可将上半平面映为单位圆。

  • 支点：绕该点一圈，多值函数值改变。几何意义：例如 ( \sqrt{z} ) 以 ( 0 ) 和 ( \infty ) 为支点。需引入支割线来分出单值分支。

二、500道典型题目分类解题方法大全

为使结构清晰，以下将500道题按知识模块分类。每类先简述核心解题方法，再以编号列表形式列举题目，每个题目后给出解题方法要点。

题型一：复数及其运算与几何表示（题1-30）

方法综述：活用 ( z = x+iy = re^{i\theta} )、( \bar{z} )、模与共轭的性质，将几何条件翻译为代数方程，或反之将方程翻译为轨迹。注意无穷远点。

  1. 化简 ( \frac{1+i}{1-i} ) 化为 ( a+bi )：分子分母同乘 ( 1+i )，得 ( \frac{(1+i)^2}{2}=i )。
  2. 幂运算 ( (1+i\sqrt{3})^{10} )：模 ( 2 )，辐角 ( \pi/3 )，结果为 ( 2^{10}e^{i10\pi/3}=1024(\cos\frac{10\pi}{3}+i\sin\frac{10\pi}{3})=-512+512\sqrt{3}i )。
  3. 二次方程 ( z^2+2z+i=0 )：求根公式 ( z=-1\pm\sqrt{1-i} )。( 1-i=\sqrt{2}e^{-i\pi/4} )，得 ( z=-1\pm\sqrt[4]{2}e^{-i\pi/8} )。
  4. 轨迹 满足 ( |z-2i| = |z+1| ) 的点集：到定点 ( (0,2) ) 和 ( (-1,0) ) 距离相等，即线段的中垂线。方程化简得 ( 2x+4y-3=0 )。
  5. 区域 画出 ( {z: 0 < \arg(z-i) < \pi/4} )：顶点在 ( i ) 的角形域，边界为从 ( i ) 出发的水平向右射线和斜向上 ( 45^\circ ) 射线。
  6. 不等式 证明三角不等式 ( |z_1+z_2| \le |z_1|+|z_2| )：两边平方，利用 ( \operatorname{Re}(z_1\bar{z}_2) \le |z_1||z_2| ) 可得。
  7. 棣莫弗 用 ( \cos\theta ) 与 ( \sin\theta ) 表 ( \sin5\theta )：由 ( (\cos\theta+i\sin\theta)^5 ) 虚部展开：( 5\cos^4\theta\sin\theta -10\cos^2\theta\sin^3\theta + \sin^5\theta )。
  8. 开方 求 ( \sqrt[3]{8i} )：( 8i=8e^{i\pi/2} )，根为 ( 2e^{i(\pi/6+2k\pi/3)} )，( k=0,1,2 )。
  9. 几何证明 证 ( z_1,z_2,z_3 ) 为正三角形顶点的充要条件：充要条件：( z_1+\omega z_2+\omega^2 z_3=0 ) 或 ( z_1^2+z_2^2+z_3^2=z_1z_2+z_2z_3+z_3z_1 )，其中 ( \omega=e^{i2\pi/3} )，利用旋转 ( \pm\pi/3 )。
  10. 指数方程 解 ( e^z = 1+\sqrt{3}i )：( 1+\sqrt{3}i = 2e^{i\pi/3} )，故 ( z = \ln 2 + i(\pi/3+2k\pi) )。
  11. 映射 ( w=z^2 ) 将第一象限映为什么？辐角加倍，第一象限 ( (0<\theta<\pi/2) ) 映为上半平面 ( (0<\phi<\pi) )。
  12. 轨迹 ( |z-1| = 2|z-i| ) 是什么曲线？设 ( z=x+iy )，平方得 ( (x-1)^2+y^2 = 4[x^2+(y-1)^2] )，整理得圆。
  13. 轨迹 ( \operatorname{Re}(z^2)=1 )：即 ( x^2-y^2=1 )，等轴双曲线。
  14. 主值 计算 ( i^i ) 主值：( i^i = e^{i\operatorname{Ln}i} )，主值支取 ( \operatorname{Ln}i = \ln 1 + i\pi/2 = i\pi/2 )，得 ( e^{-\pi/2} )。
  15. 开方 求 ( \sqrt{i} ) 的所有值：( i=e^{i\pi/2} )，平方根 ( \pm e^{i\pi/4} = \pm\left(\frac{\sqrt{2}}{2}+i\frac{\sqrt{2}}{2}\right) )。
  16. 模不等式 已知 ( |z|=1 )，求 ( |z^2+2z+1| ) 的最大值：原式 ( =|z+1|^2 )，( |z+1|\le |z|+1=2 )，最大值4。
  17. 证明 ( |z_1+z_2|^2 + |z_1-z_2|^2 = 2(|z_1|^2+|z_2|^2) )：直接展开左边即得。
  18. 方程 解 ( z^4+1=0 )：( z^4=-1=e^{i\pi} )，四个根为 ( e^{i(\pi/4+k\pi/2)} )，( k=0,1,2,3 )。
  19. 轨迹 ( \operatorname{Im}(z^2)=2 )：即 ( 2xy=2 )，双曲线 ( xy=1 )。
  20. 极坐标 将 ( -1+\sqrt{3}i ) 写成指数式：模 ( 2 )，辐角 ( 2\pi/3 )，故 ( 2e^{i2\pi/3} )。
  21. 复数积 设 ( z_1=1-i, z_2=\sqrt{3}+i )，求 ( z_1z_2 ) 的模和辐角：模相乘：( \sqrt{2}\times2=2\sqrt{2} )，辐角相加：( -\pi/4+\pi/6=-\pi/12 )。
  22. 充要条件 证 ( z ) 为实数 ( \iff z=\bar{z} )：由定义 ( x-iy = x+iy \Rightarrow 2iy=0 \Rightarrow y=0 )，几何上关于实轴对称的点重合。
  23. 复平面 指出 ( |z+i| = |z-i| ) 的轨迹：到 ( -i ) 和 ( i ) 等距，即实轴（( y=0 )）。
  24. 旋转 点 ( 1+2i ) 绕原点逆时针转 ( 90^\circ ) 得什么？乘以 ( i )，得 ( i(1+2i) = -2+i )。
  25. 距离 求点 ( i ) 到直线 ( \operatorname{Re}z=1 ) 的距离：直线 ( x=1 )，点 ( (0,1) )，距离为 ( 1 )。
  26. 线性变换 求将点 ( i ) 变为 ( -i ) 的关于实轴的反射：取共轭：( w=\bar{z} )。
  27. 模与辐角 若 ( z = \frac{1+i}{1-i} )，求 ( |z| ) 和 ( \arg z )：化简 ( z=i )，故 ( |z|=1 )，( \arg z=\pi/2 )。
  28. 不等式区域 画出 ( 1 < |z-2| < 3 )：圆环，内半径1，外半径3，圆心 ( (2,0) )。
  29. 复数平方根 ( \sqrt{3-4i} ) 两个值：设 ( (x+iy)^2=3-4i )，解方程得 ( \pm(2-i) )。
  30. 边界 描述 ( {z: \arg z = \pi/2} ) 的边界：正虚轴（不含原点）。

题型二：复变函数的极限与连续性（题31-50）

方法综述：极限定义与实数类似，关键在于 ( z ) 趋近方式是任意的。常用技巧：设 ( z=x+iy ) 转化为二元实函数极限，或利用模与三角不等式夹逼。

  1. 极限 求 ( \lim_{z \to 0} \frac{\bar{z}}{z} )：令 ( z=re^{i\theta} )，比值 ( e^{-2i\theta} )，极限依赖辐角，不存在。
  2. 极限 求 ( \lim_{z \to 0} \frac{z}{\bar{z}} )：同上，不存在。
  3. 极限 ( \lim_{z \to 0} \frac{z^2}{|z|} )：( \frac{|z|^2 e^{i2\theta}}{|z|}=|z|e^{i2\theta}\to 0 )，极限为0。
  4. 连续 讨论 ( f(z)=\frac{\operatorname{Re}z}{|z|} ) 在 ( z=0 ) 的连续性：沿不同方向趋于0时极限不同，不连续。
  5. 极限存在 证 ( \lim_{z \to 0} \frac{z^3}{|z|^2} = 0 )：( \left| \frac{z^3}{|z|^2} \right| = |z| \to 0 )。
  6. 极限 ( \lim_{z \to 0} \frac{\sin z}{z} )：重要极限，结果为 ( 1 )。可由泰勒展开或定义直接得出。
  7. 极限 ( \lim_{z \to 0} \frac{e^z-1}{z} )：幂级数首项为1，极限为1。
  8. 判断 ( f(z) = \frac{z+\bar{z}}{2} ) 在 ( z=0 ) 可导吗？即 ( \operatorname{Re}z = x )，C-R方程不满足，不可导。
  9. 连续 证 ( f(z)=\ln|z| ) 在 ( z\neq0 ) 连续：复合连续函数。
  10. 极限 求 ( \lim_{z \to \infty} \frac{2z+1}{z-i} )：分子分母同除以 ( z )，极限为 ( 2 )。
  11. 极限 ( \lim_{z \to 1+i} (z^2 - 2z + 2) )：代入即得 ( 0 )，多项式处处连续。
  12. 极限不存在 ( \lim_{z \to 0} \frac{xy}{x^2+y^2} )：沿 ( y=kx ) 极限为 ( \frac{k}{1+k^2} )，与 ( k ) 有关，不存在。
  13. 连续域 求 ( f(z)=\frac{1}{z^2+1} ) 的连续区域：分母零点 ( \pm i )，全平面除 ( \pm i ) 连续。
  14. 模极限 ( \lim_{z \to 0} z\sin\frac{1}{z} )：( |z\sin\frac{1}{z}| \le |z| \to 0 )，极限为0。
  15. 渐近 ( \lim_{z \to \infty} \frac{z^2+1}{z^2-1} )：极限为1。
  16. 极限 讨论 ( \lim_{z \to 0} \frac{\operatorname{Im}(z^2)}{|z|^2} )：( \operatorname{Im}(z^2)=2xy )，( |z|^2=x^2+y^2 )，沿不同方向极限不同，不存在。
  17. 判断 说明 ( f(z)=|z|^2 ) 在 ( z=0 ) 可导？可导，但仅在 ( z=0 ) 可导，处处不解析。
  18. 极限 ( \lim_{z \to \infty} e^{-z} )（沿正实轴）：沿 ( z=x ) 正实轴，( e^{-x} \to 0 )；沿 ( z=-x ) 负实轴，( e^{x} \to \infty )，极限不存在。
  19. 连续性 讨论 ( f(z)= ) 的连续性：( |f(z)|=|z|\to0 )，连续。
  20. 极限 已知 ( \lim_{z\to0} f(z)=A )，求 ( \lim_{z\to0} \frac{f(z^2)}{z} )：若 ( A\neq0 )，则极限不存在（无穷大）；若 ( A=0 )，需具体分析。

题型三：解析函数与柯西-黎曼方程（题51-80）

方法综述：判别可导与解析，核心是验证 C-R 方程，并确保实部、虚部偏导连续。求导数用 ( f’(z)=u_x+iv_x )。已知 ( u ) 求共轭调和函数 ( v ) 用线积分或偏积分法。

  1. 可导判别 ( f(z) = x^2 - y^2 + 2ixy )：( u=x^2-y^2, v=2xy )，( u_x=2x, v_y=2x; u_y=-2y, v_x=2y )，C-R 成立，( f(z)=z^2 )，全平面解析。
  2. 可导点 求 ( f(z)=|z|^2 ) 的可导点：( f(z)=x^2+y^2 )，( u=x^2+y^2, v=0 )，C-R 要求 ( 2x=0, 2y=0 )，仅 ( z=0 ) 可能可导，实际上可导且导数为0。
  3. 解析判别 ( f(z) = e^x\cos y + i e^x\sin y )：即 ( e^z )，全平面解析，( f’(z)=e^z )。
  4. 参数解析 确定 ( a,b,c,d ) 使 ( f(z)=x^2+axy+by^2+i(cx^2+dxy+y^2) ) 解析：令满足 C-R，对比系数得 ( a=2, b=-1, c=-1, d=2 ) 等。
  5. 极坐标 用极坐标 C-R 判断 ( f(z)=\sqrt{r}e^{i\theta/2} )（( \theta\in(0,2\pi) )）的解析性：( u=\sqrt{r}\cos(\theta/2), v=\sqrt{r}\sin(\theta/2) )，极坐标 C-R 成立，是 ( \sqrt{z} ) 分支，除原点外解析。
  6. 求导数 若 ( f(z)=u+iv ) 解析，用 ( u ) 表示 ( f’(z) )：( f’(z) = u_x - i u_y )。
  7. 解析充要条件 证明 ( f(z) ) 解析的充要条件是 ( \frac{\partial f}{\partial \bar{z}} = 0 )：由 ( \frac{\partial}{\partial \bar{z}} = \frac12(\partial_x + i\partial_y) )，展开得 C-R 方程。
  8. 反例 给出满足 C-R 但不可导的函数：例如 ( f(z)= )，偏导数存在且满足 C-R 但在0点不连续，不可导。
  9. 调和 证 ( u=x^3-3xy^2 ) 调和，并求共轭调和函数 ( v )：( \Delta u=0 )，由 ( dv=-u_y dx + u_x dy = 6xy dx + (3x^2-3y^2)dy )，积分得 ( v=3x^2y-y^3+C )。解析函数 ( z^3 )。
  10. 调和 ( u=e^x(x\cos y - y\sin y) ) 是否调和？是 ( \operatorname{Re}(ze^z) ) 的实部，显然调和。
  11. 解析验证 ( f(z)=\frac{1}{z} )，求导：( u=\frac{x}{x^2+y^2}, v=\frac{-y}{x^2+y^2} )，C-R 成立，( f’(z)=-\frac{1}{z^2} )，除 ( z=0 ) 外解析。

  2. 柯西公式 ( \oint_{|z|=2} \frac{z}{z-1} dz )：( 2\pi i \cdot 1 = 2\pi i )。
  3. 柯西公式 ( \oint_{|z|=3} \frac{\sin z}{z-\pi} dz )：( \pi ) 在圆内？( |\pi|=3.14>3 ) 不在内，积分0。
  4. 高阶导数 ( \oint_{|z|=1} \frac{\sin z}{z^3} dz )：( 2\pi i \cdot \frac{f’'(0)}{2!} = \pi i \cdot (-\sin 0)=0 )。
  5. 高阶导数 ( \oint_{|z|=1} \frac{e^z}{z^4} dz )：( \frac{2\pi i}{3!} e^0 = \frac{\pi i}{3} )。
  6. 分解 ( \oint_{|z|=1} \frac{dz}{z^2(z-2)} )：内部奇点 ( z=0 )（二阶），用高阶留数公式。
  7. 多极点 ( \oint_{|z|=1} \frac{z}{(z-1/2)^3} dz )：高阶导数：( 2\pi i \cdot \frac{f’‘(1/2)}{2!} )，其中 ( f(z)=z )，( f’'=0 )，积分0。
  8. 柯西积分公式运用 已知 ( f(z)=\oint_{|\zeta|=1} \frac{\zeta^2}{\zeta-z} d\zeta )，求 ( f(z) )：由柯西公式，( f(z)=2\pi i z^2 )（当 ( |z|<1 )）。
  9. 极限与积分 ( \lim_{R\to\infty} \oint_{|z|=R} \frac{z^2}{z^4+1} dz =0 )：大圆弧估计。
  10. 高阶导数 计算 ( f^{(n)}(0) ) 若 ( f(z)=e^{z^2} ) 通过积分表示：( f^{(n)}(0)=\frac{n!}{2\pi i}\oint \frac{e^{\zeta^2}}{\zeta^{n+1}} d\zeta )，得泰勒系数。
  11. 柯西公式逆用 若 ( \oint_{|z|=1} \frac{f(z)}{z-a} dz = 2\pi i (a^2+1) )，求 ( f(a) )：柯西公式得 ( f(a)=a^2+1 )。
  12. 积分方程 求解析函数 ( f ) 满足 ( f(z)=\frac{1}{2\pi i}\oint_{|\zeta|=2} \frac{\zeta^2}{\zeta-z} d\zeta )：当 ( |z|<2 ) 时，( f(z)=z^2 )。
  13. 多连通柯西 ( \oint_{C} \frac{f(z)}{(z-a)(z-b)}dz )，围道分别绕 ( a,b )：分解部分分式，分别用柯西公式。
  14. 导数计算 利用积分求 ( \frac{d^n}{dz^n}(z e^z) ) 在0的值：与级数比较，( n!/(n-1)! ) 等。
  15. 复积分和实积分联系 ( \frac{1}{2\pi i}\oint \frac{z^k}{z^{n+1}} dz = \delta_{kn} )：正交性。
    186-220. 综合 含各种分式及复合函数的高阶积分，均通过识别阶数和公式解决。例如 ( \oint \frac{\ln(z+1)}{z^n} dz )、( \oint \frac{e^{z}}{z^2+1} dz ) 分解等。

题型七：调和函数与共轭调和函数（题221-250）

方法综述：验证调和性（拉普拉斯为零）。已知 ( u ) 求 ( v )：利用 C-R 方程进行偏积分，或凑全微分。注意边界条件和多连通区域的周期问题。

  1. 验证 ( u=x^2-y^2+2x ) 调和，并求解析函数 ( f )：积分得 ( v=2xy+2y+C )，( f(z)=z^2+2z+C )。
  2. ( u=e^x\cos y )，求共轭调和函数：( v=e^x\sin y + C )，( f=e^z+C )。
  3. ( u=\ln(x^2+y^2) ) 是否调和？在何处？：( \Delta u=0 ) 除原点外处处调和，它是 ( 2\operatorname{Re}(\operatorname{Ln}z) )。
  4. 给定 ( v=\arctan(y/x) )，求解析函数（在右半平面）：( u=\ln\sqrt{x^2+y^2} )，( f=\operatorname{Ln}z ) 分支。
  5. 由 ( u=x/(x^2+y^2) ) 求解析函数：即 ( \operatorname{Re}(1/z) )，( f(z)=1/z )。
  6. 泊松公式初步：在单位圆上给定边界 ( u(\theta) )，求内部调和函数（提示）。
  7. 满足某条件的调和函数：若 ( u ) 调和且仅依赖于 ( r )，则 ( u=A\ln r+B )。
  8. 解析函数模的调和性：( \ln|f| ) 调和（( f\neq0 )）。
  9. 构造满足边界条件的调和函数：求解圆内狄利克雷问题用泊松积分。
    230-250. 各类共轭调和函数练习题：方法统一：偏积分或化为已知解析函数的实部/虚部。

题型八：级数与收敛半径（题251-290）

方法综述：求幂级数收敛半径用比值法 ( \lim |c_n/c_{n+1}| ) 或根值法 ( 1/\limsup \sqrt[n]{|c_n|} )。和函数可通过已知展开式或逐项积分、求导得到。

  1. 收敛半径 ( \sum_{n=1}^{\infty} \frac{z^n}{n} )：比值法 ( R=1 )。
  2. 半径 ( \sum_{n=0}^{\infty} n! z^n )：( R=0 )。
  3. 半径 ( \sum_{n=0}^{\infty} \frac{z^n}{n^n} )：根值法 ( R=\infty )。
  4. 半径 ( \sum_{n=1}^{\infty} \frac{n}{2^n}z^n )：( R=2 )。
  5. 和函数 求 ( \sum_{n=1}^{\infty} n z^{n-1} ) 的和：( \frac{1}{(1-z)^2} )，( |z|<1 )。
  6. 和函数 ( \sum_{n=0}^{\infty} \frac{z^{2n+1}}{2n+1} )：求导得 ( \sum z^{2n} = \frac{1}{1-z^2} )，积分得 ( \frac12\ln\frac{1+z}{1-z} )。
  7. 收敛域 求 ( \sum \frac{(z-i)^n}{3^n} ) 的收敛域：以 ( i ) 为圆心，半径3的圆盘。
  8. 一致收敛 证 ( \sum \frac{z^n}{n^2} ) 在闭单位圆盘上一致收敛：由魏尔斯特拉斯 M-判别法，( \sum 1/n^2 ) 收敛。
  9. 阿贝尔定理 若 ( \sum c_n ) 收敛，则 ( \lim_{r\to1^-} \sum c_n r^n = \sum c_n )：典型结论。
  10. 洛朗级数收敛域 求 ( \sum_{n=1}^{\infty} \frac{1}{z^n} + \sum_{n=0}^{\infty} \frac{z^n}{2^n} ) 的收敛环：( 1<|z|<2 )。
    261-290. 综合 含双幂级数、缺项级数、收敛半径的各种变化。

题型九：泰勒级数与洛朗级数展开（题291-350）

方法综述：在给定点展开，泰勒级数需找到距离最近奇点的距离作为收敛半径，利用已知初等函数展开式通过代换、求导、积分得到。洛朗级数在圆环内展开，常用几何级数 ( \frac{1}{1-z} ) 的变形。

  1. 将 ( \frac{1}{1+z} ) 在 ( z=0 ) 展为泰勒级数：( \sum (-1)^n z^n )，( |z|<1 )。
  2. ( e^z ) 在 ( z=1 ) 的泰勒展开：( e\sum \frac{(z-1)^n}{n!} )。
  3. ( \frac{1}{z} ) 在 ( z=i ) 展开：( \frac{1}{i+(z-i)} = -i\sum_{n=0}^{\infty} (-i)^n (z-i)^n )，( |z-i|<1 )。
  4. ( \sin z ) 在 ( z=\pi/2 ) 泰勒：利用 ( \sin(z)=\cos(z-\pi/2) )，展开。
  5. ( \frac{1}{z(z-1)} ) 在 ( 0<|z|<1 ) 内洛朗：( -\frac{1}{z} \cdot \frac{1}{1-z} = -\frac{1}{z} \sum_{n=0}^{\infty} z^n = -\sum_{n=-1}^{\infty} z^n )。
  6. 同函数在 ( 1<|z|<\infty ) 洛朗：( \frac{1}{z^2} \cdot \frac{1}{1-1/z} = \frac{1}{z^2} \sum_{n=0}^{\infty} z^{-n} = \sum_{n=2}^{\infty} z^{-n} )。
  7. ( e^{1/z} ) 在 ( 0<|z|<\infty ) 洛朗：( \sum_{n=0}^{\infty} \frac{1}{n! z^n} )。
  8. ( \frac{\sin z}{z^2} ) 在 ( 0<|z|<\infty ) 洛朗：( \frac{1}{z^2}(z - \frac{z^3}{3!}+\cdots) = \frac{1}{z} - \frac{z}{3!}+\cdots )。
  9. ( \frac{1}{z^2+1} ) 在 ( 0<|z-i|<2 ) 洛朗：分解部分分式，在 ( z=i ) 邻域展开。
  10. ( z e^{1/(1-z)} ) 在 ( 0<|z-1|<\infty ) 洛朗：令 ( w=z-1 )，( (w+1)e^{-1/w} ) 展开。
    301-350. 各类复杂函数：( \tan z )、( \cot z )、有理函数在奇点邻域的展开。常用长除法、待定系数、或利用已知级数组合。

题型十：孤立奇点类型判别（题351-390）

方法综述：找出所有奇点，对每个奇点 ( z_0 )，求极限或看洛朗展开负幂项个数。若极限有限则为可去奇点；若极限无穷且存在某整数 ( m ) 使得 ( (z-z_0)^m f(z) ) 解析且非零，则为 ( m ) 阶极点；否则为本性奇点。

  1. ( \frac{\sin z}{z} ) 在 ( z=0 )：可去奇点（极限为1）。
  2. ( \frac{1-\cos z}{z^2} ) 在 ( z=0 )：可去奇点。
  3. ( \frac{e^z-1}{z^3} ) 在 ( z=0 )：二阶极点（展开负二次幂）。
  4. ( \frac{1}{z^2(z-1)} )：( z=0 ) 为二阶极点，( z=1 ) 一阶极点。
  5. ( e^{1/z} ) 在 ( z=0 )：本性奇点。
  6. ( \frac{1}{\sin z} ) 奇点 ( z=k\pi )：一阶极点。
  7. ( \frac{z}{\tan z} ) 在 ( z=0 )：可去奇点（极限为1）。
  8. ( \sec z ) 在 ( z=\pi/2 )：一阶极点。
  9. ( \exp(\frac{1}{z^2}) ) 在 ( z=0 )：本性奇点。
  10. ( \frac{1}{e^z-1} ) 在 ( z=2k\pi i )：一阶极点。
    361-390. 更多题目涵盖多阶极点、本性奇点判定、无穷远点奇点类型。方法统一：极限法、洛朗负幂法。

题型十一：留数计算（题391-440）

方法综述：一阶极点留数公式 ( \operatorname{Res}=\lim_{z\to z_0}(z-z_0)f(z) )，或当 ( f=\frac{\varphi}{\psi} ) 且 ( \psi(z_0)=0, \psi’(z_0)\neq0 ) 时，( \operatorname{Res}=\frac{\varphi(z_0)}{\psi’(z_0)} )。高阶极点用微分公式。本性奇点只能直接展开求 ( c_{-1} )。

  1. ( \frac{e^z}{z(z-1)} ) 在 ( z=0 )：( -1 )（利用 ( \frac{e^z}{z-1} ) 代入0）。
  2. 同上在 ( z=1 ) 的留数：( e )。
  3. ( \frac{1}{z^3(z-2)} ) 在 ( z=0 )：用高阶极点公式，或展开求 ( c_{-1} )。
  4. ( \tan z ) 在 ( z=\pi/2 ) 的留数：( -1 )。
  5. ( \frac{z}{\cos z} ) 在 ( z=\pi/2 ) 的留数：( -\pi/2 )（用 ( \psi’ ) 公式）。
  6. ( \frac{e^z}{\sin^2 z} ) 在 ( z=0 )（二阶极点）：用留数公式求得 ( 1 )。
  7. ( e^{1/z} )，留数 ( z=0 )：( c_{-1}=1 )。
  8. ( \frac{z^2}{1+z^4} ) 在极点的留数和：可直接计算，注意留数和加上无穷远留数为0。
    399-440. 大量练习：包含支点的积分留数、无穷远留数利用 ( \operatorname{Res}(f,\infty)=-\operatorname{Res}(f(1/z)/z^2,0) )。

题型十二：利用留数定理计算实积分（题441-470）

方法综述：典型类型：( \int_0^{2\pi} R(\cos\theta,\sin\theta)d\theta ) 化为单位圆上的复积分；( \int_{-\infty}^{\infty} \frac{P(x)}{Q(x)}dx )，要求分母次数比分子至少高两次，常取上半圆围道；含三角函数 ( \int_{-\infty}^{\infty} f(x)e^{imx}dx ) 用约当引理。注意绕过实轴上的奇点（小圆弧引理）。

  1. ( \int_0^{2\pi} \frac{d\theta}{5+4\cos\theta} )：令 ( z=e^{i\theta} )，化为 ( \oint \frac{dz}{iz(5+2z+2/z)} )，用留数计算得 ( 2\pi/3 )。
  2. ( \int_{-\infty}^{\infty} \frac{dx}{x^2+1} )：上半圆围道，极点 ( z=i )，留数 ( 1/(2i) )，积分 ( \pi )。
  3. ( \int_0^{\infty} \frac{\sin x}{x} dx )：考虑 ( \oint \frac{e^{iz}}{z}dz )，绕过原点小圆弧，结果为 ( \pi/2 )。
  4. ( \int_{-\infty}^{\infty} \frac{\cos x}{x^2+a^2}dx )：用 ( \frac{e^{ix}}{x^2+a^2} ) 取实部，约当引理，结果 ( \frac{\pi}{a}e^{-a} )。
  5. ( \int_0^{\infty} \frac{\sqrt{x}}{x^2+1}dx )：带分支切割，取“锁孔”围道，结果为 ( \pi/\sqrt{2} )。
  6. ( \int_0^{2\pi} \frac{d\theta}{a+\sin\theta} )（( a>1 )）：化为复积分，利用单位圆内极点。
  7. ( \int_{-\infty}^{\infty} \frac{x^2}{x^4+1}dx )：上半圆两个极点，留数和 ( \pi/\sqrt{2} )。
    448-470. 含多值函数、实轴极点（柯西主值）、对数积分等各种情形。综合运用围道选择和引理。

题型十三：共形映射（题471-500）

方法综述：熟记若干基本映射：( w=z^a ) 开角域；( w=e^z ) 带域到角域；分式线性映射 ( w=\frac{az+b}{cz+d} ) 由三对对应点唯一确定，保圆、保对称。复杂区域可分解为基本映射的复合。

  1. 求将上半平面映为单位圆的映射：( w=e^{i\theta}\frac{z-\alpha}{z-\bar{\alpha}} )（( \operatorname{Im}\alpha>0 )）。
  2. 求将单位圆映为上半平面的映射：( w=i\frac{1-z}{1+z} ) 等。
  3. 求将带域 ( 0<\operatorname{Im}z<\pi ) 映为单位圆的映射：先 ( \zeta=e^z ) 映为上半平面，再用上半平面到单位圆的映射。
  4. 求将角域 ( 0<\arg z<\pi/4 ) 映为上半平面的映射：( w=z^4 )。
  5. 求将单位圆内部且沿实轴从0到1有割缝的区域映为上半平面：通过儒科夫斯基及开方等步骤复合。
  6. 证明分式线性变换的保圆性：利用方程配方或复交比。
  7. 已知三对对应点求映射：用交比相等 ( (w,w_1,w_2,w_3)=(z,z_1,z_2,z_3) ) 求解。
  8. 将上半圆 ( |z|<1, \operatorname{Im}z>0 ) 映为上半平面：先用分式线性将圆弧映为实轴，如 ( w=\frac{1+z}{1-z} ) 等。
  9. 证明 ( w=\frac{1}{2}(z+\frac1z) ) 将单位圆外部映为全平面割去 ( [-1,1] )：参数化观察。
  10. 将偏心圆环映为同心圆环的条件：涉及到共形模等高级话题，一般无初等映射。
    481-500. 各种综合映射题，包括施瓦茨-克里斯托费尔映射的简单形式（多角形）。利用映射复合表求解。
