初中数学-图形与几何

发表于2026-05-17|更新于2026-05-19|数学学习
|浏览量:

为你详细整理四川省初中数学“图形与几何”的解题方法体系，并按新课标七大知识模块分类呈现近年的中考真题及详细的分步解析资源推荐，希望能为你的高效复习提供帮助。

¶一、图形与几何复习导览

¶📐 四川省中考地位与分值构成

“图形与几何”是四川省中考数学的第一大板块（含“数与代数”并列），通常占总分的 40%~45% 。一套150分的中考试卷中，“图形与几何”相关题目通常分布在选择、填空、压轴等题位，具体包括：

题型分布 常见题号/位置 题量（参考） 分值（参考）
选择题 第26题、第812题 约6~8题 约24~32分
填空题 第13~17题 约4~5题 约16~20分
解答题 第18~25题（中档题+压轴题） 约4~6题 约28~40分

四川省各地中考的几何压轴题（通常为解答题最后两题，满分10~12分/题）几乎都以“图形与几何”为背景，涉猎三角形全等/相似的综合证明、四边形的动态几何、圆的性质探究、图形的最值/折叠/旋转等问题，在区分高分段考生中起到关键作用。

¶🎯 与“统计与概率”复习节奏的联动

“图形与几何”不同于“统计与概率”更依赖计算和图表分析，它侧重于逻辑推理和辅助线构造。因此，复习建议：

  • 基础阶段：逐个模块突破（如“三角形→全等/相似→四边形→圆→解直角三角形”），重点练透定理的运用和典型辅助线，建议每次用模拟卷中的几何中档题计时练习。
  • 强化阶段：专练几何压轴大题，建议按年份整理四川各地中考几何题的最后一题，按 “审题→提取已知→推测可能模型（如隐圆、手拉手、中点模型）→尝试构造→书写完整推理过程” 的五步流程进行训练。
  • 冲刺阶段：将“图形与几何”板块的易错题、难题与“统计与概率”等其他板块交叉练，并在模考中模拟限时作答，以适应各板块间的思维切换。

¶二、核心解题方法总览

四川省初中数学“图形与几何”板块主要涵盖：三角形（含全等、勾股定理、等腰/直角三角形、中位线等） 、四边形（含特殊平行四边形） 、相似三角形、解直角三角形（含三角函数） 、圆与正多边形以及图形的变化（轴对称、平移、旋转、位似）。

以下根据近年四川中考真题及组卷网、学科网等资源，为你系统梳理各题型对应的核心方法技巧，并配以四川中考真题案例，帮助你在具体题目中快速定位解题思路。

¶（一） 三角形与全等类

四川中考考查热点： 全等三角形的判定与应用、等腰/直角三角形的性质、中位线、三角形三边关系、勾股定理、高线/角平分线/中垂线的综合等。真题多与全等证明融合出题，且近年在中档解答题中常与四边形综合考查。

¶✅ 方法一：全等判定与辅助线构造

  • 步骤：判定两三角形全等时，先找SSS/SAS/ASA/AAS/HL所需条件是否齐备→若条件不足，考虑添加辅助线（如作高线、连接对角线、作垂线、延长线构造中点三角形等）来补全条件。
  • 例题参考（2022四川德阳） ：八一中学校九年级2班学生杨冲家和李锐家到学校的直线距离分别是3 km和5 km，那么两人家之间的直线距离取值范围是 。
    • 技巧点拨：三点构成三角形时，两边之和大于第三边、两边之差小于第三边；共线时两边之和等于第三边或两边之差等于第三边。据此可得出两人家距离范围为 2 km ≤ a ≤ 8 km，因此 1 km 不可能。此题体现了全等中三角形三边关系定理的巧妙应用。

¶✅ 方法二：等腰/等边三角形特殊模型

  • 步骤：等腰三角形问题→优先利用等边对等角、三线合一性质；等边三角形→优先利用三条线都相等、内角60°、四心合一等特征。
  • 例题参考（2022四川自贡） ：等腰三角形顶角的度数比一个底角度数的2倍多20°，求底角度数 。
    • 解析：设底角为x，则顶角为(2x+20°)，由三角形内角和定理x + x + (2x+20°) = 180°，解得x = 40°。此题通过等腰三角形内角关系建立方程，考查将文字条件转化为方程或不等式的代数推理能力。

¶✅ 方法三：三角形中位线模型

  • 步骤：已知两边中点或平行四边形对角交点时，立即联想到中位线定理→中位线平行于第三边且等于第三边的一半。
  • 技巧点拨：中位线往往和“线段长度关系”或“相似”结合，是解答题中常见的桥梁工具。

¶✅ 方法四：角平分线与垂直平分线模型

  • 步骤：遇到角平分线联想到“角平分线上的点到角两边距离相等”和“构造全等直角三角形”；遇到垂直平分线联想到“线段垂直平分线上的点到线段两端点距离相等”。
  • 四川中考特色：尺规作图（角平分线、垂直平分线作图步骤及相关性质填空），以填空题形式出现在成都、绵阳等地中考第13题左右。

小结：三角形与全等板块的核心思路是“找等量关系→建立方程或不等式→辅助线构造全等→利用中位线/垂线/高线打通几何链条”。

¶（二） 四边形与特殊平行四边形

四川中考考查热点： 平行四边形、矩形、菱形、正方形的性质及判定、中点四边形、多边形对角线/内角和、四边形与几何变换/动点问题的综合。

¶✅ 方法五：中点四边形的性质

  • 步骤：任意四边形的各边中点依次相连所得的四边形为平行四边形；若原四边形对角线相等，则中点四边形为菱形；若原四边形对角线垂直，则中点四边形为矩形；若原四边形对角线既相等又垂直，则中点四边形为正方形。
  • 真题练习：2024年四川凉山中考题——四边形各边中点分别为E、F、G、H，对角线AC = 42 cm，求四边形EFGH的周长 。
    • 技巧点拨：中点四边形周长 = 原四边形对角线之和 = 42 cm。

¶✅ 方法六：特殊平行四边形的判定与二级结论

  • 矩形判定：平行四边形 + 一个角为直角 / 对角线相等。
  • 菱形判定：平行四边形 + 一组邻边相等 / 对角线垂直。
  • 正方形判定：既是矩形又是菱形。2024年四川泸州中考题——以下条件中不能判定平行四边形为矩形的是（ ）。

¶✅ 方法七：多边形内角和/外角和/对角线通解公式

  • 内角和公式：(n−2)×180°。
  • 外角和定理：任意凸多边形的外角和恒为 360°，由此可快速求出正多边形边数：360° ÷ 每个外角度数。
  • 对角线总数公式：n(n−3)/2，过任一顶点的对角线数为 (n−3)。2024年四川巴中中考题——过五边形一个顶点有 2 条对角线。

¶✅ 方法八：平行四边形中的“X形”与“8字”相似模型

  • 模型特征：平行四边形对角线与某边中点连线相交，常出现“A字”或“8字”相似。
  • 2024四川巴中中考真题：平行四边形ABCD周长为12，对角线AC、BD交于O，点E是CD中点，AC=4，求△COE周长 。
    • 解析：OE为中位线 → OE = AB/2；CE = BC/2；CO = AC/2 = 2；故C△COE = (AB+BC+AC)/2 = (6+4)/2 = 5。

小结：四边形板块的解题口诀是——“三角形优先（中位线/全等勾股）→中点四边形记清→特殊判定分情景→动点问题巧设未知数”。

¶（三） 相似三角形

四川中考考查热点： 相似三角形的判定与性质（对应边成比例、周长比等于相似比、面积比等于相似比的平方）、金字塔模型/沙漏模型/直角三角形斜边上的高模型等在动态几何中的应用。

¶✅ 方法九：相似基本模型识别

  • A字型：两条平行线截三角形→对应边成比例；X型（沙漏） ：两直线相交截平行线形成的相似；母子型：直角三角形斜边上的高分出的两个小直角三角形与原三角形两两相似。
  • 技巧点拨：在复杂图形中，先找“谁和谁可能相似”，再验证对应角是否相等。

¶✅ 方法十：相似比与面积/周长的关系

  • 核心公式：
    • 相似三角形周长比 = 相似比；面积比 = 相似比的平方。
    • 相似多边形面积比同样适用于平方关系。
  • 真题练习：
    • 2024重庆：若两个相似三角形相似比为 1:4，则面积比为 1:16。
    • 2024四川内江：已知△ABC与△DEF相似且相似比为 2:3，则△ABC与△DEF的周长比为 2:3。

¶✅ 方法十一：方程思想求线段长

  • 步骤：相似⇒对应边成比例（列比例方程）→由已知线段表示未知线段→解方程→检验。
  • 真题练习：2024河南·中考 平行四边形ABCD中，对角线AC、BD交于O，E为OC中点，F为BE延长线与AD交点，AB=2，求DF长 。
    • 解析：由平行四边形性质及中点构造 △BCE ∽ △FOE，进而列方程求解，答案为 1。

小结：相似三角形的解题核心——“先判定再列式，比例设元求线段；面积周长比平方，基本模型记心间”。

¶（四） 圆的有关性质与综合应用

四川中考考查热点： 垂径定理、圆心角与圆周角关系、切线的性质与判定、圆与正多边形结合的面积/弧长/扇形阴影计算，以及圆与三角形、四边形、相似的融合题。

¶✅ 方法十二：垂径定理与勾股定理配合求半径

  • 步骤：直径垂直弦⇒平分弦且平分弦所对的两条弧⇒结合勾股定理求半径/弦长。
  • 真题练习：2024四川凉山——残缺圆形工件，在圆弧上任取两点A、B，作AB的垂直平分线交弧于C、交AB于D，测得CD和AB已知，求圆形工件半径 。
    • 技巧点拨：设圆心为O，则O在CD延长线上，设半径为R，则R² = (R−CD)² + (AB/2)²，求解R。

¶✅ 方法十三：圆周角与圆心角模型

  • 核心定理：同弧所对的圆心角是圆周角的2倍；直径所对的圆周角等于 90°；圆内接四边形对角互补。
  • 真题练习：2024四川成都·一模——C在以AB为直径的圆上，截取CF=CB，DE⊥AB，连结相关线段，综合运用圆周角定理和相似证明线段比例关系。

¶✅ 方法十四：切线的判定与性质综合

  • 步骤：欲证一条直线是圆的切线⇒连接圆心和直线与圆的交点（“连半径，证垂直”）⇒证明半径与该直线垂直（常用90°角的互余、平行证等）。

¶✅ 方法十五：扇形弧长与阴影面积计算

  • 弧长公式：l = nπR/180°
  • 扇形面积公式：S = nπR²/360° 或 S = lR/2。
  • 阴影面积：规则阴影 = 扇形面积 ± 三角形面积；不规则阴影可拆分成基本图形。

¶✅ 方法十六：“隐圆”模型与最值问题

  • 技巧点拨：当题中出现“直角对直径”“等角对定弦”“对角互补”等条件时，可考虑构造辅助圆来求最值（如点到圆上点距离、定角定点问题等）。

小结：圆的解题策略是——“半径作腰连垂直，圆心圆周角倍半定；切点连半径定垂直，隐圆最值模型藏辅助”。

¶（五） 解直角三角形与锐角三角函数

四川中考考查热点： 勾股定理的综合应用（含弦图）、特殊角的三角函数值（30°、45°、60°）以及解直角三角形的实际建模（仰角、俯角、方向角、坡度等）。

¶✅ 方法十七：直角三角形的边角关系（sin/cos/tan）

  • 定义：sin A = 对边/斜边，cos A = 邻边/斜边，tan A = 对边/邻边。
  • 特殊角的三角函数值：sin 30° = 1/2，cos 45° = √2/2，tan 60° = √3 等，建议编成口诀记忆。
  • 真题练习：2023四川绵阳——边长为4的正方形中，BG=3GC，点P在BC上，构造直角三角形利用三角函数求相关长度关系。

¶✅ 方法十八：勾股定理的经典模型——“赵爽弦图”

  • 技巧点拨：弦图由四个全等的直角三角形围成一个中间小正方形，可建立大正方形、小正方形、直角三角形之间的关系。
  • 真题练习（2024四川眉山） ：大正方形面积24，小正方形面积4，由四个全等直角三角形拼成，求拼成图2的大正方形面积 。
    • 解析：设直角三角形较短直角边为a、较长直角边为b，则 a² + b² = 大正方形边长²，(b−a)² = 小正方形面积；四个全等直角三角形面积=大正方形面积−小正方形面积=20，据此可求新大正方形面积。

¶✅ 方法十九：解直角三角形的实际应用

  • 应用场景：测量楼高、河宽、山高、仰俯角、坡度方向等。
  • 步骤：画示意图（标已知角与已知边）→识别直角三角形→利用三角函数列方程→解出未知量并作答。
  • 真题练习：“葭生池中”问题——方池一丈，葭生中央，出水一尺，引葭赴岸，适与岸齐，求水深。
    • 解析：设水深为x尺，则葭长为(x+1)尺，池口对角线一半为5尺，根据勾股定理得 (x+1)² = x² + 5² → 解得x = 12尺。

小结：解直角三角形的实战思路——“找直角→标数据→选函数→列方程→得答案”；遇到实际问题首先要准确画出有效的几何模型。

¶（六） 图形的变化（轴对称、平移、旋转、位似）

四川中考考查热点： 图形的基本变换（轴对称、平移、旋转），由变换生成的线段关系、角度关系，以及与最值、折叠、翻折的综合。

¶✅ 方法二十：中心对称与坐标变换

  • 步骤：点P(a, b)关于原点对称→P’(−a, −b)；关于x轴对称→P’(a, −b)；关于y轴对称→P’(−a, b)。
  • 真题练习：2024年四川成都中考——点P(−1, 2)关于原点对称的点的坐标是 (1, −2)。

¶✅ 方法二十一：折叠与轴对称构造全等

  • 技巧点拨：折叠时折痕为对称轴，对应点连线垂直于折痕，且折痕平分对应点连线。折叠往往生成轴对称图形，由此可得一系列全等三角形和等角等边关系。
  • 真题练习（2025四川德阳） ：正方形边长为4，沿EF折叠使B点落在边上，结合折叠求线段长与最值。

¶✅ 方法二十二：旋转变换与“手拉手”全等/相似

  • 步骤：旋转中心、旋转角确定⇒对应点到旋转中心的距离相等⇒对应点与旋转中心连线的夹角等于旋转角⇒常出现三角形全等或相似（尤其等腰直角三角形绕直角顶点旋转时）。
  • 真题练习：2024四川达州——含旋转的四边形综合题，通过旋转构造全等/相似，从而证明线段和差或求线段长度（具体详见“四、200道图形与几何专项练习题清单”第190~199题）。

小结：图形变换的解题要点——“对称轴判全等，坐标规律记清分；旋转中心同角找，折叠对称线连中点”。

¶三、四川省中考“图形与几何”六大核心易错点与命题陷阱

易错类型 具体表现 应对策略
等腰三角形未分类讨论 已知等腰三角形两边长，未讨论哪条边是底、哪条边是腰 要分三种情况讨论（如果只有两边已知），且每次都要验证三角形两边之和>第三边
相似三角形的对应边错配 在复杂图形中将不是对应边的线段直接列比例式 先根据“对应角相等”严格找出对应顶点，再将对应边成比例写出正确比例式
四点共圆缺少推理 直接默认某四点共圆而没有证明依据 要用“对角互补”“同弧所对圆周角相等”等条件进行严格推理后再构造辅助圆
平行四边形判定条件滥用 只用两组对边相等或一组对边平行相等就判定，忽略其他条件 复习判定链：①两组对边分别平行；②两组对边分别相等；③一组对边平行且相等；④对角线互相平分
解直角三角形忽略单位统一 在测量高楼、山高类问题中，已知条件单位不一致（如米和尺、m与cm）没有先换算 解题前先看题中长度单位是否统一，混合使用需先换算成同一单位
折叠轴对称记错对应点和相等线段 折叠后错误地认为折痕到某点的距离不变或错设相等线段 折叠所得全等关系要标注清楚，最好在图中用红色标出相等的边与角，避免视觉干扰
