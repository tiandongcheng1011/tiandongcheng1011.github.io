初中数学-统计与概率

发表于2026-05-17|更新于2026-05-19|数学学习
|浏览量:

为你系统梳理四川省初中数学“统计与概率”的解题方法，并提供分门别类的专项练习题目资源，帮助你高效备考。

一、统计部分——核心解题方法

1. 数据收集与整理类

方法一：判断调查方式的合理性

普查（全面调查）与抽样调查的选择原则：

  • 普查适用：总体中个体数量较少、准确性要求极高的情形
  • 抽样调查适用：总体中个体数量庞大、有破坏性、耗时费力或难以一一调查的情形

方法二：样本的代表性判断

判断一个抽样方法是否合理，要考虑样本是否具有随机性、是否覆盖了不同类别（分层抽样思想）、样本容量是否足够。常考的抽样方式有简单随机抽样、分层抽样、系统抽样，初中阶段重点掌握前两种的基本思想。

易错点提醒：审题时注意区分“总体”“个体”“样本”“样本容量”四个概念。样本容量只是一个数字（无单位）。

2. 三种统计图的识别与综合应用

方法三：条形统计图 → 求总体、补全图表

根据部分数据及其占比/频数，反推总人数或总频数。公式：总人数 = 已知部分人数 ÷ 该部分占比（或百分比） ，然后利用总人数减去已知各部分人数，补全条形图。

方法四：扇形统计图 → 求圆心角、各部分人数

圆心角度数公式：扇形圆心角 = 360° × 该部分占总体的百分比

从扇形图中还可以反推百分比：某部分人数对应的圆心角为θ，则该部分占总体的比例为 θ / 360° 。

方法五：折线统计图 → 描述数据变化趋势

折线图的每个点对应具体数值，主要用于观察数据随时间或次序的变化趋势，如上升、下降、波动、平稳等。

方法六：统计图综合 → 多图协同推理

将条形图（具体频数）、扇形图（比例关系）、折线图（趋势）结合，从不同维度获取信息，相互校验数据一致性。此类题通常出现在解答题第一问，是中考必考题型。

错误类型4：绘制图表和计算量时，务必“数形对照”，仔细复核图表中的数据和题目给出的数据。

3. 数据分析——集中趋势与离散程度

统计量 计算方法 易错提醒
算术平均数 一组数据的总和 ÷ 数据个数 计算时注意数据有无遗漏
加权平均数 (数据₁ × 权重₁ + 数据₂ × 权重₂ + …) ÷ 权重之和 注意加权系数是否对应正确
中位数 排序后，奇数个取中间一个，偶数个取中间两个的平均数 必须先排序
众数 出现次数最多的数据 可能不唯一，可能没有
方差 s² = [(x₁−x̄)² + (x₂−x̄)² + … + (xₙ−x̄)²] / n 方差越大，数据波动越大
极差 最大值 − 最小值 反映数据分布范围

方法七：用平均数、中位数、众数选择“代表”

评价一组数据的“一般水平”时：

  • 数据分布较均匀（无极端值）时，平均数能较好代表整体水平；
  • 数据中存在明显极端值时，中位数比平均数更能真实反映中等水平；
  • 投票类、偏好类数据（如最受欢迎的项目），众数更有说服力。

方法八：方差的应用：比较稳定性

比较两组数据的稳定性（波动大小）时，方差越小，数据越稳定。通常与平均数结合考察：先比较平均数判断“谁更好”（更大或更小视指标而定），再比较方差判断“谁更稳定”。

二、概率部分——核心解题方法

1. 事件分类

方法九：判断必然事件、不可能事件、随机事件

  • 必然事件：一定发生的事件，概率 P = 1
  • 不可能事件：一定不发生的事件，概率 P = 0
  • 随机事件：可能发生也可能不发生的事件，概率 0 < P < 1

2. 概率计算三大方法

方法 适用场景 关键技巧
枚举法（直接列举法） 试验结果种类数很少（3~4种以内） 有序列举，保证不重不漏
列表法 两步试验，结果数中等 按“行表头、列表头”方式构建表格
树状图法 两步或多步试验 从第一层开始逐层分叉，最后按路径列举

⚠️ 使用列表法或树状图的前提：①所有可能出现的结果是有限个；②每个结果出现的可能性相等。

方法十：用频率估计概率（大量试验法）

当试验次数足够大时，某事件发生的频率会稳定于其概率的附近。方法：大量重复试验 → 统计频率 → 频率近似作为概率的估计值。注意：“用频率估计概率”必须满足“大量重复试验”的条件，且当频率稳定于某个常数时，方可作估计。

方法十一：几何概型（面积法）

概率 = 所求区域面积 ÷ 总面积。初中常见的几何概率模型有：转盘问题（概率 = 扇形圆心角 / 360°）、小正方形/圆形取点问题等。

3. 概率综合应用

方法十二：放回与不放回的区别

这是概率题的最高频易错点，务必分辨！

  • 放回（有放回） ：每次抽取后球/卡放回原处，所以：

    • 每次抽取的可能结果数相同；
    • 可用组合/单独计算（两事件独立）；
    • 两次可能抽到同一球/卡。

  • 不放回（无放回） ：每次抽取后不放回，所以：

    • 每次抽取的可能结果数递减；
    • 用树状图或列表时，后续分支的选项减少；
    • 两次不会抽到同一球/卡。
特征 放回 不放回
总结果数 固定 递减
是否独立 两次抽取相互独立 两次抽取有依赖关系
列表/树状图 各层分支数相同 各层分支数逐渐减少

方法十三：游戏公平性判断

游戏是否公平，取决于双方获胜的概率是否相等。方法：

  1. 分别计算甲方赢的概率和乙方赢的概率；
  2. 比较两个概率值；
  3. 如果相等 → 游戏公平；如果不相等 → 游戏不公平，通常需修改规则（如调整得分权重）使概率相等。

方法十四：加权概率（综合成绩类）

如竞赛成绩由两个维度按一定权重计算，求某选手的综合成绩或获奖概率。综合成绩 = 控球技能分 × 60% + 投球技能分 × 40% 。

三、专项练习题（按题型分类）

以下整理了各题型典型例题及其解法要点，建议按顺序逐类练习。

(一) 统计选择题（约60题）

  1. （2025·南充）控球技能占60%、投球技能占40%，得分90分和80分，求综合成绩？ → 加权平均数公式
  2. 数据3,5,7,4,5的中位数和众数？ → 中位数先排序，众数看出现次数
  3. 45名同学视力检查，众数为4.7？ → 找出频数最大的值
  4. 盲盒质量中位数为100，添加2个盲盒后中位数仍为100 → 中位数的核心性质理解
  5. 甲、乙、丙、丁成绩平均数与方差比较 → 平均数大者好，方差小者稳定
  6. 甲乙丙丁开花时间，选最短且最平稳的 → 综合运用平均数+方差进行比较
  7. 一组数据12,12,28,35,■（30~40），■的取值不影响哪个统计量？ → 中位数不受大小极端值影响
  8. 下列事件中是必然事件的是？ → 13人中至少两人生肖相同（抽屉原理）
  9. 抛两枚硬币，必有一正一反是？ → 随机事件
  10. “石头、剪刀、布”游戏，两人获胜概率？ → 双方获胜概率相等，为1/3
  11. 前3次掷硬币都是正面，第4次正面的概率是？ → 每次独立，仍为1/2
  12. 5红3黑中“摸出红球”的概率是？ → 概率公式 P = 5/8
  13. （2023·绵阳）甲、乙、丙、丁四人射击测试，平均数9.6，方差0.25 → 选甲
  14. 6名学生体育成绩统计图，方差为1，中位数78，众数78 → 各统计量计算验证
  15. 下列事件为必然事件的是？ → 三角形内角和180°
  16. 关于x的方程ax²+4x−1=0有实数根为必然事件 → 判别式Δ≥0对任何a成立？
  17. 圆锥r、h数值，任取两个体积相同的概率 → 圆锥体积公式V=πr²h/3
  18. 4件产品1件不合格，一次抽2件 → “一合格一不合格”概率 = 1/2
  19. 统计步骤排序：采访→整理→制作扇形图→分析 → 顺序逻辑题
  20. 8个球（3白1红4黄），摸到黄球概率 = 4/8 = 1/2 → 公式法
  21. 数据2,6,5,3,2的众数和中位数 → 众数2，中位数3
  22. 某公司招聘，笔试和面试按一定权重计算 → 加权平均数
  23. 方差反映数据的什么特征？ → 离散程度/波动大小
  24. 数据中出现极端值时，哪个统计量更稳定？ → 中位数受极端值影响小
  25. 5名学生体重数据，求方差 → 公式 s² = Σ(xi−x̄)² / n
  26. 某班男生身高统计，求中位数 → 先排序，再找中间位置
  27. 某市空气质量优良天数统计 → 折线图反映趋势
  28. 扇形统计图中“篮球”对应圆心角为90°，则篮球人数占总人数多少？ → 90°/360° = 25%
  29. 200人中，喜欢红色50人，占比25%，圆心角 = 360°×25% = 90°
  30. 调查方法选择：检验一批灯泡的寿命 → 抽样调查（有破坏性）
  31. 调查方法选择：统计某班学生的视力 → 普查（人数较少）
  32. 调查方法选择：了解全市居民阅读情况 → 抽样调查（个体太多）
  33. 样本容量是300，指的是什么？ → 被调查的个体数
  34. 一组数据的方差为0 → 所有数据相等
  35. 某公司员工月薪统计，用中位数还是平均数评价？ → 有高层极高年薪，用中位数更合理
  36. 投篮命中率试验，前10次命中4次 → 用频率估计概率
  37. 折线统计图中呈上升趋势说明什么？ → 数据整体在增加
  38. 条形统计图中可以直观看出什么？ → 具体数值大小比较（直观看出谁多谁少）
  39. 某班学生期中考试成绩统计 → 平均成绩反映整体水平
  40. 下列哪个统计量可以反映数据的“平均水平”？ → 平均数、中位数都可以
  41. 为了解九年级学生体质健康，从各班随机抽取5名学生测试 → 属于哪种抽样方式？ → 简单随机抽样
  42. 某商场销售6种尺码的女鞋，条形图显示38码销量最高 → 下次进货应以38码为主
  43. 一组数据中出现多个众数 → 众数可以不止一个
  44. 在频率分布直方图中，各小长方形面积之和 = 1 → 频率之和=1
  45. 折线统计图与条形统计图的主要区别 → 折线图更强调趋势变化
  46. 扇形统计图中所有百分比之和 = 100% → 整体与部分的关系
  47. 某班50名学生血型统计，扇形图中A型占30%，圆心角 = 108°
  48. 平均数是反映数据________的统计量 → 集中趋势
  49. 为了解全校2000名学生对食堂的意见 → 应采用什么调查方式？ → 抽样调查
  50. 两个班级的平均分相同，但方差不同说明什么？ → 方差大的班级成绩分化较大
  51. 一组数据5,7,8,9,9的中位数是？ → 8
  52. 一组数据12,12,14,15,16,16的众数？ → 12和16（两个）
  53. 用样本估计总体的思想 → 样本的平均数、方差可以推断总体的大致情况
  54. 极差的计算 = 最大值−最小值
  55. 已知一组数据x1,x2,…,xn的平均数为a → 则x1+2, x2+2, …, xn+2的平均数 = a+2
  56. 已知一组数据的方差为s² → 每个数据乘以k后的方差 = k²·s²
  57. 抽样调查最关键的要素是？ → 随机性
  58. 某校参加冬奥会知识竞赛的人数统计图 → 从图中获取信息的综合分析
  59. 体重测试成绩统计 → 众数反映哪个成绩段人数最多
  60. 数据1,1,1,2,2,3的众数是？ → 1

(三) 统计填空题（约20题）

  1. 一组数据的平均数为20，各数据都减去5后新平均数是 → 15
  2. 在方差公式中，∑(x−x̄)²/n的含义是 → 方差定义
  3. 一组数据的中位数不受________的影响 → 极端值
  4. 折线图的特点是能反映数据________变化趋势 → 随着时间（次序）的变化趋势
  5. 扇形统计图各部分百分比之和为________ → 100%
  6. 加权平均数的权指的是什么 → 各数据的重要程度/系数
  7. 条形统计图中的纵轴表示什么？ → 频数或人数
  8. 某次考试全班平均分85分 → 平均分反映什么？ → 数据集中趋势
  9. 抽样调查中的样本量越大，结果越________ → 可靠（更接近总体）
  10. 普查和抽样调查的关键区别在于是否______ → 全面调查（涵盖所有个体）
  11. 频数分布直方图中，小长方形的面积与______成正比 → 各小组的频数
  12. 折线统计图中，当数据波动很大时，可以添加________来反映趋势 → 趋势线/平滑线
  13. 把一组数据从小到大排列，如果数据个数为偶数，则中位数是________ → 中间两个数的平均数
  14. 一组数据中众数不唯一的原因 → 多个数据出现频数相等且都是最高频数
  15. 数据5,6,7,8,9的平均数是 → 7
  16. 数据8,9,10,12,13的方差计算 → 公式s² = Σ(xi−x̄)² / n
  17. 在统计图表中，扇形圆心角为108° → 该部分占总人数的30% → 108°/360° = 0.3
  18. 样本容量是n → 样本中个体的数量是n
  19. 平均数、中位数、众数都可以描述一组数据的________水平 → 集中趋势
  20. 某校从每个班随机抽取5人进行调查 → 这种方式属于________抽样 → 分层抽样

(四) 概率填空题（约20题）

  1. 在大量重复试验中，某事件发生的频率逐渐稳定在0.75附近 → 该事件的概率大约是 ________ → 0.75
  2. 从一副扑克牌中抽到黑桃的概率是 ________ → 13/52 = 1/4
  3. 不透明袋中有3个白球、2个红球，不放回摸2球，摸到两个白球的概率 ________ → 树状图法
  4. 小明和3名同学站成一排拍照 → 小明站在两端的概率 ________
  5. 掷一枚均匀的骰子，点数为奇数或质数的概率 ________ → 注意“或”指并集，不重复计数
  6. 从2，3，5，7中任取两个，和为质数的概率 ________
  7. 转盘被分为4等份 → 指针指向数字1的概率 ________
  8. 一个不透明袋中有5个红球、3个蓝球、2个白球 → 摸到蓝球的概率 ________
  9. 抛两枚质地均匀的骰子，点数乘积为偶数的概率 ________
  10. 一项比赛通过抽签决定上场顺序 → 某选手第一个上场的概率 ________
  11. 盒子里有4个白球和1个红球 → 一次抽到红球的概率 ________
  12. 从10张扑克牌（红桃、黑桃各5张）中随机抽取一张，抽到红桃的概率 ________
  13. 用频率估计概率时，试验次数越多，估计值越________ → 接近实际概率
  14. 一个游戏，甲方获胜概率为2/5，乙方获胜概率为2/5，平局概率为1/5 → 游戏________ → 公平（双方获胜概率相等）
  15. 从1~20中随机抽一个数，抽到4的倍数的概率 ________ → 4的倍数有4,8,12,16,20共5个 → 5/20 = 1/4
  16. 有A、B、C三人 → 从中随机选2人 → 选到A和B的概率 ________
  17. 一个不透明的袋中有4个红球和6个黄球 → 摸出一个球是红球的概率 ________
  18. 同时掷两枚骰子，点数之和为偶数的概率 ________
  19. 某校九年级有6个班 → 从每个班中随机抽取1人参加竞赛 → 甲班被抽中的概率 ________
  20. 抛三枚硬币，两正一反的概率 ________ → 树状图法逐层展开

(五) 统计解答题（约30题）

以下10道为必练基础题（含成都中考真题改编）：

  1. （2022·成都中考） 包粽子劳动体验：等级A、B、C、D，D组8人占16% → (1)求总人数 (2)估计等级B人数 (3)从A组4人中抽2人（2男2女）抽到一男一女的概率 → 多图综合+画树状图

  2. （2021·成都中考） 篮球、足球、排球、乒乓球选课调查 → 排球30人占25% → (1)求m和n（篮球和乒乓球人数） (2)足球扇形圆心角 (3)估计2000人中选乒乓球的人数 → 扇形图+表格联用

  3. （2023·四川南充·中考真题） 某女鞋专卖店一周销售60双，条形统计图 → 下次进货量最多的是哪种尺码？ → 根据众数原理确定主力鞋码

  4. （四川省凉山州2024年中考） 最喜欢的球类项目调查 → 条形图扇形图结合 → (1)总人数 (2)补全条形图 (3)从最喜欢篮球的甲、乙、丙、丁四人中选两人进行访谈 → 抽到甲和乙的概率 → 列表法求概率

  5. （成都2026届中考一轮训练） 调查视力健康数据 → 已知部分学生近视情况，求扇形圆心角、补全直方图、估计全校近视人数 → 利用样本估计总体

  6. 端午节活动：“包粽子”“划旱船”“诵诗词”“创美文” → 调查结果扇形图 → (1)求m (2)“诵诗词”圆心角 (3)估计全校2000人中选某类的人数 (4)从4人中选2人 → 甲、乙同时被选中的概率

  7. 错题整理调查 → A：很少，B：有时，C：常常，D：总是 → 补全条形图 + 求扇形圆心角 + 从A类和D类中各选两人 → 再从这4人中抽2人，抽到“很少”和“总是”各一人的概率

  8. 科技创新实验演示调查：A自动升高的水、B不会湿的纸、C漂浮的硬币、D生气的瓶子 → 求总人数，补全统计图 → 从4人中抽2人作为实验演示员 → 两人来自不同班级的概率

  9. 阅读课外书问卷调查：条形图与扇形图结合 → 扇形圆心角度数计算 + 样本估计总体 + 补全统计图

  10. 环保宣传活动参与情况调查：条形统计图 → 求总人数，补全条形图，估计全校参与人数

以下10道为进阶难度题（适用于拔高训练）：

  1. 五种果树种植比例 → 扇形图与条形图结合 → 从种植数据中找中位数、平均数

  2. 垃圾分类调查：50名学生 → 绘制扇形统计图 → 计算垃圾投放正确率的频数分布表

  3. 各年级视力状况对比：多组数据统计量对比 → 比较不同年级视力的集中趋势与离散程度

  4. 体育成绩统计：6名学生成绩 → 判断说法哪项错误（涉及方差、中位数、众数、极差）→ 逐一验证各统计量

  5. 九年级模拟考试：全年级数学成绩频数分布直方图 → 补全直方图，求及格率，估计优秀人数

  6. 某校900名学生身高统计 → 频数分布直方图 → 估算平均身高（近似法：用组中值×频数 / 总人数）

  7. 某公司员工工资表 → 对比平均数与中位数 → 反映工资真实情况应选用哪个？

  8. 甲乙两支篮球队赛季得分统计表 → 比较两队平均得分与稳定性（标准差/方差比较）

  9. 某地区空气质量指数（AQI）连续30天统计 → 绘制折线图，分析污染趋势

  10. 七年级与八年级数学竞赛成绩比较 → 用平均数、中位数、方差说明两个年级成绩各有什么特点

以下10道为灵活创新题：

  1. 校园歌手大赛评分：去掉一个最高分、去掉一个最低分后求平均分 → 统计学的“修剪平均”应用

  2. 从一批产品中抽查，用样本不合格率估计总体不合格率 → 用频率估计概率思想

  3. 统计图中的“数据丢失”题 → 已知部分数据，反推缺失数据 → 利用平均数/中位数/众数的定义建立方程求解

  4. 天气预测与降水量数据 → 统计图表中的时间序列趋势分析 → 用折线图进行预报

  5. 交通拥堵情况的调查：各时间段车辆流量条形图 → 根据图表提出交通改善建议

  6. 健身活动参与情况统计 → 结合两个统计图，找出矛盾信息并修正

  7. 手机使用时长调查 → 频数分布直方图与扇形图结合 → 从统计角度分析青少年手机使用问题

  8. 菜市场进货决策：根据条形图中的销量众数决定进货量 → 统计量在实际经营决策中的应用

  9. 某学校兴趣小组选择情况 → 扇形图中给出比例（如篮球30%、足球20%等），求各小组具体人数

  10. 校运动会报名统计：条形图与表格联用 → 求解缺失的报名人数，并估计全校参与情况

(六) 概率解答题（约30题）

以下10道为基础题：

  1. 一个不透明的袋中装有4个红球和6个白球 → (1)一次取出红球的概率 (2)有放回取2次，两次都红球的概率 → 区分放回与不放回

  2. 甲、乙两人玩石头剪刀布游戏 → (1)求甲赢的概率 (2)游戏是否公平？ → 枚举法 + 公平性判断

  3. 从2,3,4,5四张卡片中随机抽2张 → (1)组成两位数的概率 (2)两位数是奇数的概率 → 列表法

  4. 掷两枚质地均匀的骰子 → 列出所有可能结果 → 概率问题解答（如点数之和等于7的概率）

  5. 从甲、乙、丙、丁4人中随机抽取2人参加活动 → 列出所有可能结果，求抽到甲和乙的概率

  6. 班级组织春游，从3个景点中随机选择2个 → (1)列出所有选择方案 (2)求包含某景点A的概率

  7. 一个不透明盒子里有5颗糖果（2颗巧克力味、3颗草莓味），不放回取2颗 → 求两颗都是草莓味的概率 → 树状图或列表

  8. 小明从4道题中随机抽1题 → 是数学题的概率（假设数学题有1道）

  9. 从甲、乙、丙三名班干部中随机选2人 → (1)所有可能结果 (2)甲被选中的概率

  10. 一个圆形转盘被分成6个等份扇形，数字分别为1,2,3,4,5,6 → 求指针指向偶数的概率（公式法）

以下10道为典型应用题：

  1. 甲、乙两人玩“掷两枚骰子，点数之积”游戏 → 根据计算结果判断游戏公平性

  2. 某商场促销：抽奖箱中有4个红球3个蓝球2个黄球，摸到红球为一等奖 → 求摸到一等奖的概率

  3. 某快递公司因恶劣天气导致延误 → 根据往年数据统计，求延误的概率 → 用频率估计概率

  4. 英语单词拼写游戏，从8个字母中随机抽4个 → 求恰好能拼出某个单词的概率

  5. 小明口袋中有2枚1元硬币和3枚5角硬币，随机取出2枚 → 求面值之和大于2元的概率

  6. 从一副扑克牌（去掉大小王）中随机抽取两张（不放回） → 求两张都是红桃的概率

  7. 从8名同学中随机选3人参加演讲比赛 → 求甲、乙、丙三人同时被选中的概率

  8. 幸运抽奖转盘：红、黄、蓝三色区域面积比1:2:3 → 求指针落在蓝色区域的概率 → 几何概率

  9. 某公司安全知识竞赛，共有5道判断题，答对任意3道及以上为通过 → 求通过的概率（需考虑排列组合）

  10. 两个不透明的盒子：A中有2红1白，B中有3红2白 → 从两个盒子中各随机取一球 → 求两球颜色相同的概率 → 树状图法，分层次枚举

以下10道为综合题（统计+概率融合）：

  1. （2022·自贡） 包粽子劳动体验调查：等级统计图 → 先补全图表 → 再用列表法求从A组4人（2男2女）中抽到一男一女的概率

  2. （四川省凉山州） 最喜欢球类项目调查：条形图+扇形图结合 → 补全统计图 → 再用树状图求从4人中抽2人恰好是甲和乙的概率

  3. 社会实践活动调查：先通过扇形图算出总人数和各类别人数 → 再用列表法计算抽到特定组合的概率

  4. 九年级学生期中考试数学成绩统计图 → 求平均分和中位数 → 再从班级中随机抽取一名学生，求其成绩高于平均分的概率

  5. 校园才艺大赛调查：补全条形图 → 用样本估计全校参加人数 → 从获奖学生中随机抽1人，求抽到某特长学生的概率

  6. 体育社团选课情况统计：用统计图求m、n → 再求扇形圆心角 → 最后从4人中抽2人 → 抽到特定两人的概率

  7. 垃圾分类宣传成效调查：用扇形图分析投放正确率 → 再从样本中随机选1人 → 求投放正确的概率

  8. 学生视力检查数据表：求众数和平均数 → 再用频率估计近视率 → 在近视学生中随机抽一人，求其近视度数>400度的概率

  9. 某校学生阅读统计：用频数分布直方图 → 求中位数 → 再从全校随机抽1人 → 求其阅读时间超过中位数的概率

  10. 成都中考A卷15题模拟：不完整图表 → (1)补全统计图，求总人数 (2)用样本估计总体 (3)从4人中抽2人 → 抽到特定组合的概率 → 全面训练统计图表应用能力
