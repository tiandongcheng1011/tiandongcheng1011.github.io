高中数学-数列与不等式

发表于2026-05-17|更新于2026-05-19|数学学习
|浏览量:

“数列与不等式”是高中数学的重要板块，也是四川新高考解答题的压轴常客。数列作为定义在正整数集上的特殊函数，与不等式结合后灵活多变，既考查运算功底，更考查构造与放缩的思维能力。

以下系统梳理数列与不等式的知识体系、核心解题方法，并给出200道分类练习题清单与复习建议。

一、数列篇——核心解题方法

（一）等差/等比数列的基本运算

方法一：基本量法（通法）

  • 步骤：等差数列的关键量是首项a₁和公差d；等比数列的关键量是首项a₁和公比q。利用通项公式和前n项和公式，将已知条件转化为关于这些基本量的方程（组），解出后再求所需。
  • 适用：已知两个及以上条件求通项或和。

方法二：等差/等比数列的性质

  • 等差数列：若m + n = p + q，则a_m + a_n = a_p + a_q；S_{2n-1} = (2n-1)·a_n。
  • 等比数列：若m + n = p + q，则a_m·a_n = a_p·a_q；S_n, S_{2n}-S_n, S_{3n}-S_{2n}仍成等比（公比q^n）。
  • 易错：等比数列前n项和公式需分q=1和q≠1两种情况讨论。

方法三：下标变换求特定项——利用等差中项/等比中项法快速定位中间量。

  • 技巧：已知Sₙ求aₙ，有公式aₙ = Sₙ - S_{n-1}（n≥2），且需单独验证a₁。
  • 2024年新课标Ⅱ卷真题：记Sₙ为等差数列{aₙ}的前n项和，若a₃ + a₇ = 10，a₄·a₆ = 9，求公差d和S₅。解法：由a₃+a₇=2a₅⇒a₅=5；由a₄·a₆= a₅² - d² = 25 - d² = 9⇒d²=16⇒d=±4；S₅=5a₃=25。体现利用下标和性质简化运算。

（二）数列求通项——五大核心方法

题型特征 方法名称 核心步骤 示例/公式
a_{n+1} - a_n = f(n) 累加法 a_n = a₁ + Σ_{k=1}^{n-1} f(k) 适用差式为等差数列前n-1项和
a_{n+1} / a_n = f(n) 累乘法 a_n = a₁ × Π_{k=1}^{n-1} f(k) 要求所有项非零
a_{n+1} = pa_n + q (p≠1) 构造等比法 化为a_{n+1} + λ = p(a_n + λ)，解得λ = q/(p-1) {a_n + λ}为等比数列
a_{n+1} = pa_n + f(n) 待定系数构造 设a_{n+1} + g(n+1) = p[a_n + g(n)]，通过比较系数确定g(n) 当f(n)为一次式/指数形式时适用
a_{n+1} = \frac{pa_n}{qa_n + r} 取倒数法 两边取倒数，转化为\frac{1}{a_{n+1}} = \frac{q}{p} + \frac{r}{p}·\frac{1}{a_n} 形如a_{n+1} = \frac{k a_n}{a_n + m}，则{1/a_n}为等差
已知Sₙ = f(aₙ)或Sₙ = g(n) 利用aₙ = Sₙ - S_{n-1}消去Sₙ ①先求a₁ = S₁；②n≥2时aₙ = Sₙ - S_{n-1}；③验证n=1是否满足 关键：注意n=1的检验

方法四：已知Sₙ与aₙ的混合关系求通项

  • 技巧：用aₙ = Sₙ - S_{n-1}将Sₙ消去，化为aₙ与a_{n-1}的递推关系；或消去aₙ，化为Sₙ与S_{n-1}的递推关系。

（三）数列求和——四大核心方法

求和类型 方法名称 适用场景 核心公式/技巧
等差/等比数列 公式法 直接给出等差或等比形式 S_{n(等差)} = n(a₁+a_n)/2；S_{n(等比)} = a₁(1-qⁿ)/(1-q)
a_n = 1/[n(n+k)] 或类似 裂项相消法 通项可拆分为两项之差 常用裂项：1/(n(n+1)) = 1/n - 1/(n+1)；1/((2n-1)(2n+1)) = ½[1/(2n-1) - 1/(2n+1)]
a_n = (an+b)·qⁿ 错位相减法 等差数列 × 等比数列的形式 Sₙ = a₁ + a₂ + … + aₙ；qSₙ错一位相减，化简求和
a_n + a_{n+1} = f(n) 并项求和 奇偶项符号相反或相消 将相邻两项结合为一个整体求和
含(-1)ⁿ的摆动数列 奇偶分项求和 奇项与偶项规律不同 设n为奇数或偶数分别讨论，或在n/2的基础上处理

方法五：等差/等比片段和性质快速求和——等差数列片段和S_m, S_{2m}-S_m, S_{3m}-S_{2m}……成等差；等比数列对应成等比。

  • 技巧：利用片段和性质可绕开求首项直接算和。

（四）数列的单调性与最值

方法六：判断数列单调性的常用方法

  • 作差法：计算a_{n+1} - a_n，判断符号。若各项均为正，也可用a_{n+1}/a_n与1比较（作商法）。
  • 函数法：将a_n视为f(n)（定义域为正整数），利用导数研究对应函数f(x)在[1, +∞)上的单调性。
  • 等差/等比直接判断：d > 0时递增，d < 0时递减；q > 1且a₁ > 0时递增，0 < q < 1时递减。

方法七：求数列最大/最小项

  • 策略：找相邻项关系，解不等式组aₙ ≥ a_{n+1}且aₙ ≥ a_{n-1}（最大项）；类似方法求最小项。

二、不等式篇——核心解题方法

（一）不等式的性质与解法

方法八：不等式基本性质的应用

  • 可加性：a > b ⇒ a + c > b + c
  • 可乘性：a > b，c > 0 ⇒ ac > bc；c < 0 ⇒ ac < bc
  • 同向可加性：a > b，c > d ⇒ a + c > b + d
  • 同向可乘性：a > b ≥ 0，c > d ≥ 0 ⇒ ac > bd

方法九：一元二次不等式解法

  • 步骤：①将不等式化为ax² + bx + c ≥ 0（a > 0）标准形式；②解对应方程ax² + bx + c = 0得根；③根据“大于取两边，小于取中间”确定解集。注意a < 0时先化为正。

方法十：分式不等式与绝对值不等式

  • 分式：移项通分化为\frac{P(x)}{Q(x)} ≥ 0，等价于P(x)·Q(x) ≥ 0且Q(x) ≠ 0。
  • 绝对值：|x| < a ⇔ -a < x < a（a > 0）；|x| > a ⇔ x < -a 或 x > a。

（二）基本不等式及其应用

方法十一：基本不等式（均值不等式）

  • 公式：a + b ≥ 2√(ab)（a, b ≥ 0），等号在a = b时取到。
  • 变形：ab ≤ (a + b)²/4；a² + b² ≥ 2ab。
  • 一正二定三相等：使用前必须检查各项为正、和为定值或积为定值、等号能否取到。

方法十二：基本不等式的常见应用场景

  • 求最值：和为定值时，积有最大值；积为定值时，和有最小值。
  • 构造定值技巧：“1”的代换——若有a + b = 1，则1/a + 1/b = (a+b)/ab + ……常用。
  • 易错：多次使用基本不等式时，必须保证等号能同时成立。

（三）数列不等式的证明

方法十三：数学归纳法证明数列不等式

  • 步骤：①验证n = 1时不等式成立；②假设n = k时成立，证明n = k + 1时也成立；③综合结论。
  • 适用：与正整数n相关的不等式，尤其是结构与递推关系紧密的类型。

方法十四：构造函数法（函数单调性法）

  • 步骤：将数列不等式视为函数问题。例如证明a_n > b_n，可构造函数f(x) = a(x) - b(x)，利用导数判断f(x) > 0。
  • 核心：数列可看作定义域为正整数的特殊函数，其单调性、有界性都可借助对应函数分析。
  • 2025考纲重点：要求建立“求导→判号→构造→证明”的完整逻辑链。

方法十五：分析法与综合法

  • 分析法：从结论出发，反向推导到已知条件。“要证P，只需证Q”。
  • 综合法：从已知条件出发，逐步推导到结论。
  • 技巧：证明数列不等式时，常从要证结论倒推至数列通项的特征。

方法十六：比较法（作差法/作商法）

  • 作差法：证明a_n ≥ b_n，转化为证明a_n - b_n ≥ 0。常用技巧：通分、配方、因式分解。
  • 作商法：当a_n, b_n均为正时，证明a_n / b_n ≥ 1。常用于等比型数列之间的比较。
  • 应用：比较两个数列的大小、证明单调性、证明累加累乘型不等式。

（四）放缩法（数列不等式核心进阶技巧）

方法十七：放缩法的五大基本策略

放缩法是数列不等式证明中最灵活的技巧，核心是将复杂的通项缩放为可求和的形式。

策略 核心思想 常用放缩公式
裂项放缩 将a_n放大或缩小为可裂项相消的形式 1/(n(n+1)) < 1/n² < 1/((n-1)n)（n≥2）；1/n² < 1/(n²-1) = ½[1/(n-1) - 1/(n+1)]
等比放缩 将a_n放大为等比数列，利用等比求和公式 利用二项式定理：(1 + 1/n)ⁿ < e < 3
保留前几项 前几项不缩放，从某项开始放缩 常用于a_n无法整体求和时
不等式放缩 利用常见不等式（如ln(1+x) < x，e^x ≥ 1+x） 糖水不等式：若a > b > 0，m > 0，则a/b > (a+m)/(b+m)
递推放缩 利用递推关系逐层放缩 形如a_{n+1} = f(a_n)时，通过分析f的单调性放大到等比形式

方法十八：放缩的方向控制

  • 放大：分母变小、分子变大、减小或增加项。
  • 缩小：分母变大、分子变小、舍去正项。
  • 核心：必须保证放缩后的表达式能明确求和，不能“放过头”导致无法证明原不等式。

三、数列与不等式交汇——综合题型方法

方法与题型对应表

题型 解题突破口 常用技巧
Sₙ与不等式的恒成立问题 先求aₙ或Sₙ，将不等式化为最值问题 分离参数：a ≥ f(n)恒成立 ⇒ a ≥ max f(n)
Sₙ与不等式的有解（能成立）问题 存在n使不等式成立 ⇒ a ≥ min f(n) 与恒成立条件恰好相反，易错但关键
aₙ ≤ 某常数恒成立 用单调性求aₙ的最大值 若数列递减，最大值在n=1处；若先增后减，求导找极值
数列前n项和的放缩 将通项缩放为可求和形式 裂项放缩/等比放缩
奇偶数列问题 按n的奇偶性分类 分别写出奇数项和偶数项的通项
数列新定义问题 理解新定义的含义 从特殊到一般，先模拟小规模情形找规律
数学归纳法证明不等式 验证n=1；假设n=k成立推n=k+1 在递推步骤中灵活运用假设条件

常见题型详解

题型一：数列与不等式恒成立问题

已知含参不等式恒成立，求参数范围。解法：先将参数分离，转化为a ≥ f(n)或a ≤ f(n)对一切n恒成立，则a ≥ f(n)的最大值（或a ≤ f(n)的最小值）。关键在于准确求出数列的最值——可通过分析单调性或求导得出。

题型二：数列与不等式有解（存在性）问题

存在n使不等式成立时，条件变为a ≥ f(n)的最小值（或a ≤ f(n)的最大值），与恒成立恰好相反。

题型三：奇偶数列问题

当数列通项按奇偶呈现不同规律时（如(-1)ⁿ形式），按n的奇偶性分别讨论奇数项和偶数项的通项公式，再分别求和。

2026四川模考示例：数列{a_n}通项公式为a_n = 2n-1（n为奇数）、2ⁿ（n为偶数），求前10项和。解法：奇数项求和S奇 = 1+3+5+7+9=25；偶数项求和S偶 = 2²+2⁴+2⁶+2⁸+2¹⁰ = 4+16+64+256+1024=1364；S₁₀ = 1389。

题型四：数列新定义问题

2024年新课标Ⅰ卷首次出现数列新定义压轴题——“可分数列”。近年四川模拟卷也在数列试题中加入创新元素。应对策略：①理解新定义的核心要义；②从n取较小值入手，按定义验算找出规律；③将问题转化为已知的数列模型。

六、核心公式与技巧速记卡

数列求通项速记：

  • 累加：a_{n+1} - a_n = f(n) ⇒ a_n = a₁ + Σf(k)
  • 累乘：a_{n+1}/a_n = f(n) ⇒ a_n = a₁ × Πf(k)
  • 构造：a_{n+1} = pa_n + q ⇒ 加λ = q/(p-1) 构造等比
  • 倒数：a_{n+1} = pa_n/(qa_n + r) ⇒ 取倒数后为等差

裂项相消常用公式：

  • 1/[n(n+1)] = 1/n - 1/(n+1)
  • 1/[(2n-1)(2n+1)] = ½[1/(2n-1) - 1/(2n+1)]
  • 1/[√n + √(n+1)] = √(n+1) - √n

数列不等式放缩常用不等式：

  • 1/k² < 1/[k(k-1)] = 1/(k-1) - 1/k（k ≥ 2）
  • 1/√k < 2(√k - √(k-1))
  • 糖水不等式：a/b > (a+m)/(b+m)（a > b > 0，m > 0）
