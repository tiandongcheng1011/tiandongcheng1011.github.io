高中数学-立体几何与空间向量

发表于2026-05-17|更新于2026-05-19|数学学习
|浏览量:

“立体几何与空间向量”是高中数学的核心板块，也是四川新高考解答题的必考模块。与“函数与导数”的代数推理不同，立体几何重在空间想象与代数计算的双重能力。同时，它不像“数列与不等式”那样依赖构造与放缩的灵活技巧，而是强调坐标建系、向量运算的规范性与准确性。

以下系统梳理立体几何的知识体系、核心解题方法，并给出200道分类练习题清单与复习建议。

一、四川高考中的“立体几何与空间向量”

在四川新高考（新高考Ⅱ卷）中，立体几何通常占分12—16分，约占总分的8%—11%。一般分布为：选择题1—2道（小题），填空题1道，解答题1道。其中解答题通常采用 “一半证明，一半计算” 的结构——第一问考查线面位置关系的证明，第二问涉及空间角或距离的计算。

在教材中，立体几何分为两个阶段：必修部分（必修第二册）侧重几何直观与综合法，选择性必修部分（选择性必修第一册）引入空间向量，作为解决立体几何问题的核心工具。

三、核心解题方法——六大类，二十法

（一）空间几何体——基础计算类

方法一：三视图还原几何体
根据三视图（主视图、左视图、俯视图）还原几何体的常见策略：①找底面——从俯视图入手；②定高度——依据主视图和左视图中的高线；③补全顶面——判断锥体还是柱体。

  • 易错提醒：三视图中的虚线表示被遮挡的棱，还原时不可遗漏；斜二测画法下，直观图面积 = 原图面积 × √2 / 4。

方法二：柱、锥、台、球的表面积与体积公式

  • 柱体：V = Sh
  • 锥体：V = Sh/3
  • 台体：V = (S上 + S下 + √(S上·S下))·h/3
  • 球体：S = 4πR²，V = 4πR³/3
  • 适用：直接已知几何体的基本量时，代入公式计算。

方法三：等体积法（转换顶点）求点到平面距离
“等体积法”的核心思想是：同一个三棱锥，从不同顶点计算其体积应相等。常用于：

  • 已知条件：不易直接作出垂线时。
  • 步骤：①确定以谁为底、谁为高的体积公式；②建立方程V = V，解出所求距离。
  • 应用场景：求点到平面的距离、求点到直线的距离、求两个平行平面间的距离。

（二）点、直线、平面位置关系——综合法类

方法四：线面平行的判定与证明

  • 核心定理：若平面外一条直线与此平面内的一条直线平行，则该直线与此平面平行。
  • 关键辅助线：寻找或构造平面内与已知直线平行的直线——常利用中位线、平行四边形对边、面面平行的交线。
  • 易错提醒：“线面平行”和“面面平行”的判定定理易混淆，注意定理的前提条件——线面平行要求“平面外的直线”与“平面内的直线”平行，缺一不可。

方法五：线面垂直的判定与证明

  • 核心定理：若一条直线垂直于平面内的两条相交直线，则该直线垂直于该平面。
  • 关键思路：在平面内找两条相交直线与该直线垂直——常用三垂线定理及其逆定理作为找垂直的辅助工具。

方法六：面面垂直的判定与性质

  • 判定：若一个平面经过另一个平面的一条垂线，则这两个平面互相垂直。
  • 性质：两平面垂直时，其中一个平面内垂直于交线的直线垂直于另一个平面。
  • 适用范围：第一问证明题，通常需综合运用线面垂直的判定和面面垂直的性质。

方法七：面面平行的判定与性质

  • 判定：若一个平面内的两条相交直线都与另一个平面平行，则这两个平面平行。
  • 性质：①平行平面间的交线互相平行；②平行平面间的距离处处相等。

方法八：三线合一与转化思想
在复杂几何体中，将空间问题转化为平面问题处理是重要策略：

  • 利用中位线：三角形两边中点连线平行于第三边。
  • 利用平行四边形性质：找到平行且相等的线段。
  • 利用垂线：从空间一点向平面作垂线，射影等性质。

（三）空间向量——坐标法与基底法类

方法九：坐标法解题的核心步骤
①建立空间直角坐标系（找到共起点的三条两两垂直的线）；②写出关键点的坐标；③写出相关向量的坐标；④利用向量的运算公式求夹角、距离或证明位置关系；⑤转化为几何结论。

方法十：空间直角坐标系建系策略
建系的核心是找到三条两两垂直的线共点。常见建系方式：

几何体类型 推荐建系方式 难点与对策
长方体/正方体 以一角为原点，三条棱为坐标轴 最易建系，坐标直观
直棱柱 以底面一角为原点，侧棱为z轴 底面需为直角三角形或特殊四边形
正棱锥/圆锥 以底面中心为原点，底面所在平面为xOy面，高线为z轴 底面正多边形时，底面顶点坐标可用三角函数表示
三棱锥 以某一底面为xOy面，以该面的高线为z轴 当底面不是直角三角形时，顶点坐标较复杂
无天然垂直关系 先证垂直，再建系；或利用已知线段长度设未知数 可用“底图法”在底面图形中确定坐标
  • 易错提醒：建系前必须确保三条轴两两垂直，若垂直关系不明显，要先在几何上证明垂直后再建系。建系后应尽量使关键点在坐标轴或坐标平面上，以简化运算。

方法十一：基底法（非坐标向量法）
当三个基底向量不易找垂直关系时，可选取三个不共面的向量作为基底，利用空间向量基本定理将任意向量用基向量表示。基底法尤其适用于：

  • 四面体（以同一顶点出发的三条棱为基底，夹角已知但非直角）。
  • 平行六面体（以同一顶点出发的三条棱为基底）。
  • 建系困难、点坐标无法直接确定的几何题。
  • 选用原则：①三个基底向量必须不共面；②基底向量的长度和夹角应已知或易求。

（四）空间角与距离——向量计算类

方法十二：异面直线所成角

  • 向量公式：设a、b分别为两条直线的方向向量，θ为异面直线所成角（取锐角或直角），则 cos θ = |a·b| / (|a|·|b|) 。

方法十三：直线与平面所成角（线面角）

  • 向量公式：设l的方向向量为v，平面α的法向量为n，θ为直线与平面所成角（取锐角），则 sin θ = |v·n| / (|v|·|n|) 。
  • 与线线角的区别：线面角是用sin，而线线角和二面角通常用cos，这是最易混淆之处。

方法十四：二面角（平面与平面所成角）

  • 向量公式：设n₁、n₂分别为两个平面的法向量，二面角θ（通常取锐角或钝角，依题目要求确定），则 |cos θ| = |n₁·n₂| / (|n₁|·|n₂|) 。
  • 若需确定二面角是锐角还是钝角，应观察两法向量的方向（指向平面同侧还是异侧）。
  • 易错提醒：线面角用sin，二面角用cos，这两者常因混淆而造成失分。

方法十五：点到平面的距离

  • 向量公式：设平面α的法向量为n，P为平面外一点，A为平面内任意一点，则点P到平面α的距离为 d = |(AP·n)| / |n| 。
  • 另解：等体积法（见方法三）。
  • 适用：向量法适用于任何有坐标系的情景，是通法。

方法十六：点到直线的距离

  • 向量公式：设直线l的方向向量为v，点P到直线l上一点A的距离为 d = |AP × v| / |v|（AP为从A指向P的向量）。

（五）外接球与内切球——模型公式类

方法十七：外接球八大模型

模型类型 适用几何体 球半径公式（R） 推导技巧
墙角模型（长方体模型） 三条棱两两垂直的三棱锥（长方体的一个角） R = √(a² + b² + c²)/2 直接补成长方体，体对角线的一半即为球半径
圆柱模型 底面为圆形的直棱柱 底面外接圆半径r、高h，R = √[r² + (h/2)²] 球心位于棱柱轴线的中点
圆锥模型 圆锥 底面外接圆半径r、高h，R² = (h - R)² + r² 球心在高线上，列方程求R
正四面体模型 正四面体 R = √6·a/4（a为棱长） 正四面体的中心即球心
对棱相等四面体 三组对棱相等的四面体 R = √[(a² + b² + c²)/8]（a,b,c为三组对棱的长度） 补成长方体
棱切球模型 正多面体（各棱均与球相切） R = √[(a² + b² + c²)/4] 补成长方体
等腰四面体 同一顶点的三条棱两两垂直 同墙角模型 见墙角模型
正棱锥模型 正棱锥 列方程：R² = (h - R)² + r² 球心在高线上，高线长度h

方法十八：内切球半径

  • 等体积法：设多面体的体积为V，表面积为S，内切球半径为r，则 r = 3V / S。
  • 适用场景：任何多面体均可用此公式。
  • 易错提醒：求V和S时注意多面体的构成，不要漏面。

（六）动态几何与截面问题——压轴突破类

方法十九：截面形状的判断与性质
截面问题的核心是利用“面面平行的性质”：用一个平面截棱柱或棱锥，截面平行于底面时，截面形状与底面相似；截面不平行于底面时，截面形状为多边形，其顶点位于棱上。

  • 常见题型：正方体的截面形状可以是三角形、四边形、五边形、六边形（但不能是正五边形和七边形及以上）。
  • 策略：①确定截面与几何体各棱的交点；②按顺序连接交点；③判断截面图形的形状。

方法二十：动点轨迹问题

  • 定性判断：动点的轨迹常在柱面、球面、圆锥面上。
  • 定量计算：将动点的坐标用参数表示，根据约束条件列出方程，判断轨迹类型。
  • 近年趋势：截面及动点压轴问题成为立体几何小分题的新热点。

六、核心公式与技巧速记卡

建系口诀：

长方正方角做原点，直棱柱以底面为面；正锥建在中心和底面，底面梯形先找直角边。无天然垂直证再建，点有参数参先行。

空间角公式速记：

角度类型 公式 记忆要点
异面直线所成角 cos θ = |a·b|/(|a||b|) 取锐角，用cos
线面角 sin θ = |v·n|/(|v||n|) 用sin，与二面角区分
二面角 cos θ = |n₁·n₂|/(|n₁||n₂|) 取锐角时取绝对值，钝角需判断

常用向量运算公式：

运算 坐标形式
向量点积 a·b = a₁b₁ + a₂b₂ + a₃b₃
向量模长 |a| = √(a₁² + a₂² + a₃²)
点到平面距离 d = |AP·n|/|n|
法向量求法 n = a × b（向量积）

外接球八大模型口诀：

墙角补长方体，圆柱求中垂线；正四面体记常数，对棱相等看补全；圆锥列方程，球心在高线上。
