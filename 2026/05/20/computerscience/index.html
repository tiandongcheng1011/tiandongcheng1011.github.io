大学计算机-计算机算法

发表于2026-05-20|更新于2026-05-20|计算机
|浏览量:

下面在梳理主流算法与解题思路的基础上，为每类算法精选一道经典题目，并给出完整的 C++ 解答。代码均经过思维验证，可直接作为模板使用。

一、算法体系与解题思路速览

算法大类 核心思想 典型应用 解题要点
排序 比较排序 O(n log n)；非比较排序 O(n) 预处理、选取、区间合并 根据数据规模、稳定性、空间限制选择
搜索 DFS 遍历状态，BFS 求最短步数，二分加速判定 迷宫、最短路径、答案范围二分 状态空间较大时注意剪枝或启发式
图论 最短路、生成树、网络流、拓扑序 路径规划、依赖关系、连通性 建模是关键，边权正负决定算法选择
分治 分解→递归→合并 排序、求第K大、大数乘法 递推式配合主定理分析复杂度
动态规划 最优子结构 + 重叠子问题 背包、LIS、编辑距离、树形DP 定义状态与转移方程，可加滚动数组优化
贪心 局部最优导出全局最优 活动选择、哈夫曼、部分背包 必须证明正确性，常与排序/堆配合
回溯 试探+剪枝 全排列、N皇后、组合总和 明确递归树，设计剪枝条件降低搜索量
字符串 前缀函数、字典树、后缀结构 模式匹配、子串查询 KMP 避免回溯，Trie 加速前缀匹配
数值/数论 快速幂、筛法、GCD、FFT 模运算、多项式乘法、质数 预处理与数学化简
数据结构技巧 单调栈/队列、并查集、树状数组、线段树 滑动窗口最值、动态连通性、区间查询 用空间换时间，加速特定操作

二、经典题目与 C++ 实现

1. 分治 / 快速选择：数组中的第K个最大元素

题目：给定整数数组 nums 和整数 k，返回数组中第 k 个最大的元素（非排序后的第 k 个）。
思路：基于快速排序的分区操作，每次确定一个 pivot 的最终位置。若 pivot 位置正好是第 k 大（即 n-k 索引），则找到；否则只递归一侧。平均 O(n)，最坏 O(n²)（可随机化避免）。

2. 二分搜索：寻找旋转排序数组中的最小值

题目：一个原本升序的数组在某个下标旋转后作为输入，数组元素互不相同，找出最小元素。
思路：二分查找，比较中间值与右边界值。若 mid 小于 right，最小值在左半部分（包含 mid）；否则在右半部分。O(log n)。

3. 图论 / 拓扑排序：课程表

题目：需修习 numCourses 门课程，某些课程有先修要求。判断能否完成所有课程。（LeetCode 207）
思路：将课程依赖抽象为有向图，判断是否有环。BFS 拓扑排序：统计入度，将入度为 0 的节点入队，逐个移除并更新后继入度。若最终处理的节点数等于课程总数，则无环。

4. 动态规划：最长递增子序列 (LIS)

题目：给定整数数组，找到最长严格递增子序列的长度。
思路 1：O(n²) DP，dp[i] 表示以 i 结尾的 LIS 长度。
思路 2（更优）：O(n log n) 贪心 + 二分。维护数组 tails，其中 tails[k] 表示长度为 k+1 的递增子序列的最小结尾值。遍历每个数，二分查找第一个大于等于它的位置并更新。

5. 贪心：跳跃游戏 II

题目：非负整数数组，每个元素代表最大跳跃长度。从起始位置到末尾的最少跳跃次数。
思路：贪心，在每一步可到达的范围内，选择能使下一步到达最远的位置。维护当前步的边界 end 和可达的最远距离 maxPos。到达边界时步数加一，更新边界。

6. 回溯：全排列

题目：不含重复数字的数组，返回所有可能的全排列。
思路：回溯算法。使用一个 used 数组标记已选元素，递归地选择剩余的数字。深度到达数组长度时收集结果。

7. 字符串 / KMP：实现 strStr()

题目：给定 haystack 和 needle，返回 needle 第一次出现的位置，不存在返回 -1。
思路：KMP 算法，通过构建模式串的 next（前缀函数）数组，避免主串指针回溯。时间复杂度 O(n+m)。

8. 数值 / 快速幂：Pow(x, n)

题目：实现 pow(x, n)，即 x 的 n 次幂。
思路：快速幂（二分求幂）。将 n 用二进制表示，迭代计算。注意 n 可能为负数。时间复杂度 O(log n)。

9. 滑动窗口 / 双指针：无重复字符的最长子串

题目：给定字符串，找出不含有重复字符的最长子串的长度。
思路：滑动窗口 + 哈希集合（或直接用数组记录字符最后出现位置）。右指针不断右移，若出现重复，左指针跳到重复字符下一位置。均摊 O(n)。

10. 并查集：省份数量

题目：有 n 个城市，isConnected 矩阵表示它们的连接关系。省份是一组直接或间接相连的城市。求省份数量。
思路：并查集（Union-Find）。遍历矩阵，将相连的城市合并。最后统计根节点的不同数量。

#include <vector>
using namespace std;

class UnionFind {
    vector<int> parent, rank;
public:
    UnionFind(int n) {
        parent.resize(n);
        rank.resize(n, 0);
        for (int i = 0; i < n; ++i) parent[i] = i;
    }
    int find(int x) {
        return parent[x] == x ? x : parent[x] = find(parent[x]);
    }
    void unite(int x, int y) {
        int rx = find(x), ry = find(y);
        if (rx != ry) {
            if (rank[rx] < rank[ry]) parent[rx] = ry;
            else if (rank[rx] > rank[ry]) parent[ry] = rx;
            else { parent[ry] = rx; ++rank[rx]; }
        }
    }
    int count() {
        int cnt = 0;
        for (int i = 0; i < parent.size(); ++i)
            if (parent[i] == i) ++cnt;
        return cnt;
    }
};

class Solution {
public:
    int findCircleNum(vector<vector<int>>& isConnected) {
        int n = isConnected.size();
        UnionFind uf(n);
        for (int i = 0; i < n; ++i)
            for (int j = i + 1; j < n; ++j)
                if (isConnected[i][j] == 1) uf.unite(i, j);
        return uf.count();
    }
};
