大学计算机-计算机算法综述

排序类 冒泡排序 相邻元素比对，逆序交换，大数沉底 原地修改，仅临时交换变量，内存低 小规模数据简易排序
选择排序 每轮选最值，放到已排序区间头部 原地查找，仅下标标记，内存极低 找数组第N小/大元素
插入排序 依次插入前方已排序有序序列 原地移位，仅存待插入值，内存稳定 几乎有序数组排序
希尔排序 分组插入排序，逐步缩小分组间隔 原地分组，无额外数组，开销小 中等规模数组优化排序
快速排序 选基准分左右（左小右大），递归排序 原地交换，递归占用栈内存 大数据量高速排序
归并排序 二分拆分，再有序合并子序列 开辟临时数组，内存占用翻倍 外排序（超大文件排序）

查找类 顺序查找 从头到尾逐个遍历比对目标值 零额外开销，无内存改动 无序数组元素查找

分治算法 分治算法 拆分相同子问题，求解后合并 递归占用栈内存，无堆内存开销 快速/归并排序底层、汉诺塔
动态规划 动态规划（DP） 拆分重叠子问题，记录最优解 开辟dp数组，存储中间最优解 背包问题、斐波那契数列
贪心算法 贪心算法 每步选局部最优，推导全局最优 仅记录当前最优，内存极简 零钱兑换、活动安排
图论算法 Dijkstra（迪杰斯特拉） 求带权无负权图单源最短路径 开距离、标记数组，静态存储 城市最短路线规划
Floyd（弗洛伊德） 多源最短路径，暴力中转节点 开辟n*n矩阵，内存占用大 全图任意两点最短距离
BFS（广度优先搜索） 层序遍历，先同层再下层 借助队列，动态占用内存 迷宫最短路径、层序遍历
DFS（深度优先搜索） 深挖分支，回溯再遍历其他分支 递归栈/栈容器，占用栈内存 全排列、岛屿数量统计
字符串算法 KMP算法 字符串匹配，用前缀表跳过无效比对 开辟前缀数组，少量线性内存 文本关键词快速查找
回溯算法 回溯算法 尝试方案，错误则回退撤销 递归栈+临时路径，深度影响内存 数独、N皇后、全排列

大学计算机课程中涵盖的经典算法很多，这里选取 排序、查找、图、动态规划 四类中最具代表性的 5 个算法进行归纳。每个算法都从 中文描述、内存变化、图例、5 个实际应用问题 四个维度展开。

¶1. 冒泡排序

中文描述
重复遍历数组，依次比较相邻的两个元素，如果顺序错误就交换它们。每一轮遍历会将当前未排序部分的最大（或最小）元素“浮”到最后面，就像气泡上浮一样。

内存上的变化

  • 主要在原数组上进行就地交换，仅需一个临时变量 temp 存储交换值。
  • 数组元素逐步变得有序，内存中的排列从无序区逐渐向有序区收缩。
  • 若提前有序则可通过标志位提前结束，减少不必要的比较，但空间复杂度恒为 (O(1))。

算法图例
初始数组： [5, 3, 8, 1]

需要该算法解决的 5 个特定问题

  1. 对班级小型成绩单（几十条记录）进行快速升序排列。
  2. 判断一个未知序列是否已经完全有序（利用提前终止特性）。
  3. 扑克牌游戏起手牌按点数从小到大整理。
  4. 传感器短时间内采集的温度数据排序，用于平滑滤波预处理。
  5. 小型比赛积分榜，当参赛者数量较少时直接用于排名。

¶2. 二分查找

中文描述
在有序数组中，每次取中间位置的元素与目标值比较：若相等则找到；若目标较小，则在左半部分继续查找；若目标较大，则在右半部分查找。重复直到找到目标或搜索区间为空。

内存上的变化

  • 仅维护三个整型变量 low、high、mid，分别表示当前查找区间的左右边界和中点。
  • 每次比较后，low 或 high 的值发生改变，区间长度减半。
  • 没有额外数组分配，内存占用 (O(1))，仅几个整型变量值在不停变化。

算法图例

需要该算法解决的 5 个特定问题

  1. 在按姓名拼音排序的电子电话簿中快速查找联系人。
  2. 判断某个用户 ID 是否存在于已排序的百万级用户名单中。
  3. 在英汉词典（按字母序）中查找一个单词的释义。
  4. 从按时间戳排序的日志文件中，快速定位某一秒内产生的记录。
  5. 数值计算中，使用二分法逼近求解平方根或方程根。

¶3. 快速排序

中文描述
每次选择一个“枢轴”（pivot），将数组划分为两部分：左边的元素都小于等于枢轴，右边的都大于等于枢轴，然后对左右两部分递归地进行同样的操作，直到整个数组有序。

内存上的变化

  • 排序是原地的，通过交换元素改变数组内存布局。
  • 递归调用会消耗栈空间：平均情况栈深 (O(\log n))，最坏情况 (O(n))。
  • 需要几个临时变量保存枢轴值、左右扫描指针 i、j 以及递归时的参数。

需要该算法解决的 5 个特定问题

  1. 对大规模数据库记录进行内存排序（如 MySQL 排序缓冲区）。
  2. 查找数组中第 k 小的元素（快速选择算法，快速排序思想的变种）。
  3. 操作系统按文件大小排序显示目录内容。
  4. 编程语言标准库中 sort() 的底层实现（C 标准库 qsort）。
  5. 海量数据中快速筛选 Top K 元素（利用划分位置）。

¶4. 迪杰斯特拉最短路径算法

中文描述
从源点出发，维护一个当前已知最短距离集合。每次从未处理节点中选取距离最小的节点，松弛它的所有邻居（更新更短距离），直到所有节点都处理完毕，得到源点到各点的最短路径。

内存上的变化

  • 维护数组 dist[]：记录源点到每个节点的当前最短距离，值不断被更新变小。
  • 维护布尔数组 visited[] 或标记。
  • 常用最小优先队列（二叉堆）存储待处理节点，堆内元素不断弹出和压入。
  • 距离数组从初始的 ∞（或极大值）逐步收敛到最终的最短距离值。

算法图例
图：A—(4)—B，A—(2)—C，B—(1)—C，B—(5)—D，C—(3)—D，从 A 出发。

需要该算法解决的 5 个特定问题

  1. 地图导航软件计算两地之间的最短驾驶距离或时间。
  2. 计算机网络路由协议（如 OSPF）计算最优数据包转发路径。
  3. 社交网络中计算两个人之间的最短关系链（六度分隔）。
  4. 游戏 AI 在网格地图上的自动寻路（结合曼哈顿距离）。
  5. 物流配送中，规划从中心仓库到多个客户的总行程最短路径。

¶5. 动态规划 — 0/1 背包问题

中文描述
给定若干件物品，每件有重量和价值，背包有总容量限制。每件物品只能选 0 件或 1 件，求使总价值最大的选取方案。通过构建 dp[i][w] 表格表示前 i 件物品在容量 w 下的最大价值，逐步递推求解。

内存上的变化

  • 核心是填充二维数组 dp[][]（或优化为一维滚动数组）。
  • 随着 i 和 w 增长，dp[i][w] 被逐一计算并填入，数值从 0 逐渐增长到最优解。
  • 可压缩空间：用一维数组 dp[w]，从后向前更新，内存中这些数值不断被更大的价值替代。
  • 最终 dp[n][W] 或 dp[W] 保存最大总价值。

算法图例

需要该算法解决的 5 个特定问题

  1. 投资组合选择：在有限资金下，选择多个项目（每个只能选一次）使总收益最大。
  2. 货运装载：飞机货舱限重下，选择不同重量和运费的货物使总运费最高。
  3. 预算限制下，选购家电组合使家庭综合满意度指数最高。
  4. 任务调度：每个任务占用一定时间并带来收益，在总可用时间内选取任务使收益最大化。
  5. 信息隐藏（隐写术）：在有限容量的载体中，选择最合适的文件组合以嵌入最大有效数据量。

这 5 个算法覆盖了排序、查找、分治、图、动态规划等核心思维，能够帮助你建立

起对算法设计中内存变化、过程可视化、实际应用三位一体的理解。

在大学计算机课程或计算思维基础中，常会围绕几种核心的算法策略来讲解问题求解。下面归纳五种最典型的算法，给出中文描述、算法图例，并列出各自能解决的5个具体问题。

¶6. 枚举法（穷举法）

中文描述
按照某种顺序逐一列举所有可能的候选解，并依次检验每个候选是否满足问题的约束条件，从而找出全部合法的解。思路简单，但对规模较大的问题效率很低。

算法图例

flowchart TD
    A[开始] --> B[确定枚举范围和步长]
    B --> C{还有下一个候选?}
    C -->|是| D[取出当前候选解]
    D --> E{满足所有条件?}
    E -->|是| F[记录或输出该解]
    E -->|否| C
    F --> C
    C -->|否| G[结束]

解决特定问题5个

  1. 百元买百鸡问题
  2. 水仙花数（阿姆斯特朗数）查找
  3. 鸡兔同笼问题
  4. 寻找1000以内的所有完数
  5. 简单密码暴力破解（纯数字组合）

¶7. 递推与递归

中文描述

  • 递推：从已知的初始条件出发，依据递推关系一步步推导出后续结果。
  • 递归：一个函数直接或间接调用自身，将原问题分解为规模更小、结构相同的子问题，直到达到可直接求解的边界条件。

算法图例（计算斐波那契数列递归树）

graph TD
    fib5["fib(5)"] --> fib4["fib(4)"]
    fib5 --> fib3a["fib(3)"]
    fib4 --> fib3b["fib(3)"]
    fib4 --> fib2a["fib(2)"]
    fib3a --> fib2b["fib(2)"]
    fib3a --> fib1a["fib(1)"]
    fib3b --> fib2c["fib(2)"]
    fib3b --> fib1b["fib(1)"]

解决特定问题5个

  1. 计算阶乘 n!
  2. 汉诺塔问题
  3. 斐波那契数列
  4. 二叉树的前序、中序、后序遍历
  5. 文件夹及其子目录的遍历

¶8. 分治算法

中文描述
将原始问题分割成若干个规模较小、相互独立且与原问题形式相同的子问题，递归求解各个子问题，最后将子问题的解合并成原问题的解。典型步骤为：分解 → 求解 → 合并。

算法图例（归并排序的分治过程）

graph TD
    A[原数组] --> B[左半部分]
    A --> C[右半部分]
    B --> D[左左子数组]
    B --> E[左右子数组]
    C --> F[右左子数组]
    C --> G[右右子数组]
    D --> H[排序与合并]
    E --> H
    F --> I[排序与合并]
    G --> I
    H --> J[合并后有序数组]
    I --> J

解决特定问题5个

  1. 归并排序
  2. 快速排序
  3. 二分查找
  4. 大整数乘法（Karatsuba算法）
  5. 棋盘覆盖问题

¶9. 贪心算法

中文描述
在每一步选择中都采取当前状态下最好或最优的决策，从而希望最终得到全局最优解。贪心选择后不可回退，只适用于具有贪心选择性质和最优子结构的问题。

算法图例（硬币找零贪心流程）

flowchart TD
    Start["开始: 剩余金额 = 要找零的总额"] --> CoinList["列出可用硬币面值(从大到小)"]
    CoinList --> Pick{"选择最大面值 ≤ 剩余金额"}
    Pick -->|"找到"| Output["输出该硬币"]
    Output --> Update["剩余金额 = 剩余金额 - 该面值"]
    Update --> Check{"剩余金额 = 0?"}
    Check -->|"是"| End["结束"]
    Check -->|"否"| Pick

解决特定问题5个

  1. 硬币找零问题（在标准面值系统下使用最少硬币）
  2. 活动选择问题（安排最多不冲突活动）
  3. 哈夫曼编码（最优前缀码构造）
  4. Dijkstra 单源最短路径算法
  5. Prim 最小生成树算法

¶10. 动态规划

中文描述
把复杂问题分解为相互重叠的子问题，通过保存子问题的解来避免重复计算。通常采用自底向上的填表方式，利用状态转移方程由已解决的子问题推导出更大问题的解，适合最优决策类问题。

算法图例（0/1背包问题DP表格填充示意）

flowchart LR
    subgraph DP表
        direction LR
        T0["dp[0][*] = 0"] --> T1["dp[1][*]"]
        T1 --> T2["dp[2][*]"]
        T2 --> T3["..."]
        T3 --> TN["dp[n][W]"]
    end
    Item["当前物品 i \n重量 w_i, 价值 v_i"] -->|状态转移| Cal["dp[i][j] = max(dp[i-1][j], dp[i-1][j-w_i] + v_i)"]
    Cal --> T2

解决特定问题5个

  1. 0/1背包问题
  2. 最长公共子序列（LCS）
  3. 最短编辑距离（Levenshtein距离）
  4. 矩阵链乘问题（最优加括号方式）
  5. 最长递增子序列（LIS）
